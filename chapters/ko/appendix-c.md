# 부록 C: 개념 레지스트리

책에서 소개된 모든 핵심 개념을 해당 챕터, 사용된 비유, 그리고 등장하는 SAA-C03 도메인에 매핑했습니다.

이것을 학습 색인으로 사용하십시오. 시험 전에 어떤 개념이 헷갈린다면, 여기에서 찾아 맥락을 위해 해당 챕터로 돌아가십시오.

---

## A

**ACM (AWS Certificate Manager)** — ALB, CloudFront, API Gateway를 위한 무료 퍼블릭 TLS 인증서로, DNS 검증을 통해 자동 갱신됩니다. CloudFront 인증서는 us-east-1에 있어야 합니다. 16장. 도메인 1.

**ACU (Aurora Capacity Unit)** — Aurora Serverless v2 용량의 측정 단위입니다. 자동으로 확장되며, 지원되는 엔진 버전에서는 열린 연결이 없을 때 0 ACU로 자동 일시 중지할 수 있습니다. 24장. 도메인 3.

**Alarm (CloudWatch)** — 지표가 임계값을 넘으면 발동하여 알림이나 Auto Scaling 작업을 트리거하는 규칙입니다. 7장. 도메인 2.

**ALB (Application Load Balancer)** — 경로와 호스트 규칙에 따라 HTTP/HTTPS 트래픽을 라우팅하는 계층 7 로드 밸런서입니다. 7장. 도메인 2.

**AMI (Amazon Machine Image)** — EC2 인스턴스의 OS, 소프트웨어, 구성을 담은 템플릿입니다. 4장. 도메인 3.

**아키텍트 사고방식** — "이것이 어떻게 작동하는가?"만이 아니라 "무엇이 먼저 고장 나는가, 우리는 그것을 어떻게 아는가, 그리고 새벽 3시에 누군가는 무엇을 하는가?"를 묻는 것입니다. 32장, 34장. 교차 도메인.

**아키텍처 결정 기록(ADR)** — 결정, 그 대안, 근거, 그리고 무엇이 재고를 유발할지를 담은 짧은 문서입니다. 32장. 교차 도메인.

**아키텍처 검토** — 제약 → 미지수 → 옵션 → 장애 모드 → 모니터링 → 런북을 다루는 구조화된 프로세스입니다. 32장. 교차 도메인.

**Athena** — S3의 데이터를 위한 서버리스 SQL 쿼리 서비스입니다. 스캔된 TB당 지불합니다. Parquet/ORC 컬럼형 형식에 가장 적합합니다. 26장. 도메인 3.

**Auto Scaling 그룹(ASG)** — 함께 관리되는 EC2 인스턴스 그룹으로, 비정상 인스턴스를 자동으로 교체하고 부하에 따라 확장합니다. 7장. 도메인 2, 3.

**가용 영역(AZ)** — 낮은 지연 시간의 링크로 연결된, 리전 내의 하나 이상의 물리적으로 분리된 데이터 센터입니다. 2장. 도메인 2.

## B

**AWS Backup** — EBS, RDS, DynamoDB, EFS, Storage Gateway 전반에 걸친 중앙 집중식 정책 기반 백업입니다. 교차 리전 및 교차 계정 복사를 지원합니다. 18장, 23장. 도메인 2.

**AWS Batch** — Docker 컨테이너를 위한 관리형 배치 컴퓨팅입니다. 작업 정의(무엇을 실행할지), 작업 대기열(작업이 대기하는 곳), 컴퓨팅 환경(EC2 또는 Fargate, On-Demand 또는 Spot)으로 구성됩니다. Lambda의 15분 제한을 초과하는 워크로드용입니다. 21장. 도메인 3.

**버킷(S3)** — S3 객체의 컨테이너입니다. 버킷은 전역적으로 고유한 이름을 가지며 특정 리전에 존재합니다. 5장. 도메인 3.

**버킷 정책** — S3 버킷에 연결되어 IAM 주체와 외부 계정의 접근을 제어하는 리소스 기반 정책입니다. 5장. 도메인 1.

## C

**캐시 어사이드 패턴** — 애플리케이션이 먼저 캐시를 확인하고, 미스 시 데이터베이스를 쿼리한 다음 결과를 캐시에 저장합니다. 10장. 도메인 3.

**캐시 적중률** — 오리진이 아니라 캐시에서 처리되는 요청의 비율입니다. 높을수록 좋습니다. 13장. 도메인 3.

**AWS Client VPN** — 관리형 OpenVPN 엔드포인트입니다. 개별 디바이스(노트북, 워크스테이션)를 인터넷을 통해 VPC에 연결합니다. 인증은 Active Directory, 자격 증명 공급자와의 SAML 2.0 페더레이션, 또는 상호 TLS를 통합니다. 스플릿 터널과 풀 터널 모드를 지원합니다. Site-to-Site VPN(네트워크 대 네트워크)과 대조됩니다. 11장. 도메인 1.

**CloudFront** — AWS CDN입니다. 전 세계 750개 이상의 엣지 로케이션에 콘텐츠를 캐싱합니다. 지연 시간과 오리진 데이터 전송 비용을 줄입니다. 13장. 도메인 3, 4.

**CloudTrail** — 모든 AWS API 호출을 기록합니다: 누가, 무엇을, 언제, 어디서. S3에 저장됩니다. 감사와 인시던트 조사에 사용됩니다. 도메인 1.

**CloudWatch** — AWS 리소스와 사용자 지정 애플리케이션을 위한 지표, 로그, 경보, 대시보드입니다. 책 전반에서 참조됩니다. 모든 도메인.

**Amazon Cognito** — 애플리케이션 최종 사용자를 위한 인증입니다: User Pool은 관리형 사용자 디렉터리(가입, 로그인, MFA, 소셜 로그인, JWT)이고, Identity Pool은 임시 AWS 자격 증명을 발급합니다. IAM은 엔지니어를 위한 것이고, Cognito는 고객을 위한 것입니다. 14장. 도메인 1.

**콜드 스타트(Lambda)** — Lambda가 실행 환경을 초기화하는 동안 첫 호출(또는 비활성화 후) 시 발생하는 지연입니다. 제거하려면 프로비저닝된 동시성을 사용합니다. 20장. 도메인 3.

**Compute Savings Plan** — 시간당 EC2 지출 금액에 대한 약정으로, 모든 인스턴스 유형이나 크기에 적용됩니다. 27장. 도메인 4.

**Config (AWS)** — 시간에 따른 AWS 리소스 구성 변경을 추적하고 규칙에 대해 규정 준수를 평가합니다. 31장. 도메인 1.

**AWS Control Tower** — 다중 계정 거버넌스를 자동화합니다: 가드레일이 있는 랜딩 존(관리, 로그 아카이브, 감사 계정)을 몇 분 만에 구축합니다 — Organizations, CloudTrail, Config를 직접 연결하는 작업의 사전 제작 버전입니다. 14장. 도메인 1.

**교차 AZ 데이터 전송** — 리전 내 가용 영역 간의 트래픽입니다. 각 방향당 GB당 $0.01이 부과됩니다. 30장. 도메인 4.

**교차 리전 복제** — 데이터(S3 CRR, Aurora Global, DynamoDB Global Tables)를 다른 리전으로 복사하는 것입니다. 데이터 전송 요금이 발생합니다. 18장, 23장, 30장. 도메인 2.

## D

**AWS DataSync** — 파일 공유(NFS/SMB)를 S3, EFS, 또는 FSx로 마이그레이션하고 동기화하는 에이전트 기반 서비스입니다. "AWS 콘솔이 달린 rsync 강화판." 25장. 도메인 3.

**DAX (DynamoDB Accelerator)** — 특별히 DynamoDB를 위한 인메모리 캐시입니다. 마이크로초 읽기 지연 시간을 제공합니다. 9장. 도메인 3.

**데드 레터 큐(DLQ)** — 처리에 반복적으로 실패한 메시지가 전송되는 대기열로, 대기열 막힘을 방지합니다. 19장. 도메인 2.

**AWS DMS (Database Migration Service)** — 최소 다운타임으로 데이터베이스를 AWS로 마이그레이션합니다. 전체 로드(초기 복사)와 CDC(Change Data Capture)가 마이그레이션 중 소스와 대상을 동기화 상태로 유지합니다. 동종 마이그레이션(동일 엔진 유형): DMS 직접 사용. 이기종 마이그레이션(서로 다른 엔진 유형, 예: Oracle → Aurora PostgreSQL): SCT(Schema Conversion Tool)를 먼저 사용한 다음 DMS. 8장. 도메인 3.

**Dedicated Host** — 여러분의 독점 사용을 위해 예약된 물리적 EC2 서버입니다. 특정 소프트웨어 라이선스에 필요합니다. 27장. 도메인 4.

**심층 방어** — 여러 보안 제어(IAM + 보안 그룹 + NACL + WAF + GuardDuty)를 계층화하여 한 계층의 침해가 시스템을 노출시키지 않도록 하는 것입니다. 33장. 도메인 1.

**Direct Connect** — 온프레미스 위치에서 AWS로의 전용 프라이빗 네트워크 연결입니다. VPN보다 일관됩니다. 25장. 도메인 3.

**DLQ** — 데드 레터 큐 참조.

**DynamoDB** — 어떤 규모에서도 한 자릿수 밀리초 지연 시간을 제공하는 완전 관리형 NoSQL 데이터베이스입니다. 키-값 및 문서 모델. 9장. 도메인 3.

**DynamoDB Auto Scaling** — CloudWatch 지표에 따라 프로비저닝된 읽기/쓰기 용량을 자동으로 조정합니다. 29장. 도메인 4.

**DynamoDB Streams** — DynamoDB 테이블의 모든 항목 변경에 대한 시간순 변경 로그입니다. 이벤트 기반 처리를 위해 Lambda와 함께 사용됩니다. 9장. 도메인 2.

## E

**EBS (Elastic Block Store)** — 단일 EC2 인스턴스에 연결되는 블록 스토리지입니다. 독립적으로 지속됩니다. 유형: gp3, io2, st1. 6장. 도메인 3.

**EC2 (Elastic Compute Cloud)** — 클라우드의 가상 머신입니다. 4장. 도메인 3.

**ECS (Elastic Container Service)** — 관리형 컨테이너 오케스트레이션입니다. Fargate 시작 유형은 서버 관리를 제거합니다. 21장. 도메인 2, 3.

**EFS (Elastic File System)** — 여러 EC2 인스턴스에서 접근 가능한 공유 NFS 파일 시스템입니다. 자동으로 확장됩니다. 스토리지 클래스에는 Standard, Infrequent Access, Archive가 있으며, 계층 간 자동 이동을 위한 Intelligent-Tiering이 있습니다. 6장. 도메인 3.

**EKS (Elastic Kubernetes Service)** — AWS의 관리형 Kubernetes 컨트롤 플레인입니다. 21장. 도메인 3.

**Elastic Disaster Recovery (DRS)** — 서버(온프레미스 또는 EC2)를 저비용 스테이징 영역에 연속 블록 수준으로 복제하고, 복구 인스턴스를 몇 분 만에 실행합니다 — 관리형 파일럿 라이트입니다. 18장. 도메인 2.

**ElastiCache** — 관리형 인메모리 캐싱입니다. Redis(더 풍부한 기능) 또는 Memcached(더 단순). 10장. 도메인 3.

**Elastic IP** — 할당하여 EC2 인스턴스에 재연결할 수 있는 정적 퍼블릭 IP 주소입니다. 11장. 도메인 3.

**봉투 암호화** — 데이터를 데이터 키(DEK)로 암호화하고, DEK를 마스터 키(KMS의 CMK)로 암호화하는 패턴입니다. 16장. 도메인 1.

**EventBridge** — AWS 서비스, SaaS 파트너, 사용자 지정 소스의 이벤트를 대상으로 라우팅하는 이벤트 버스입니다. 예약 규칙을 지원합니다. 22장. 도메인 2.

**명시적 거부** — 어떤 허용으로도 재정의될 수 없는 IAM 거부 문입니다. 모든 허용보다 우선합니다. 3장. 도메인 1.

## F

**장애 조치 라우팅(Route 53)** — 기본 엔드포인트가 상태 확인에 실패하면 보조 엔드포인트로 트래픽을 라우팅합니다. 12장. 도메인 2.

**Fargate** — ECS와 EKS를 위한 서버리스 컴퓨팅 엔진입니다. 관리할 EC2 인스턴스가 없습니다. 21장. 도메인 3.

**팬아웃 패턴** — 하나의 SNS 토픽이 동일한 메시지를 여러 SQS 대기열에 동시에 전달합니다. 19장. 도메인 2.

**FIFO 대기열(SQS)** — 정확히 1회 처리, 엄격한 순서. 표준 대기열보다 낮은 처리량. 19장. 도메인 2.

**장애 모드** — 시스템이 실패할 수 있는 특정한 방식입니다. 프로덕션 전에 장애 모드를 식별하는 것이 아키텍처 검토의 핵심입니다. 32장. 교차 도메인.

---

## G

**게이트웨이 엔드포인트** — S3와 DynamoDB를 위한 무료 VPC 엔드포인트 유형입니다. AWS 프라이빗 네트워크를 통해 트래픽을 라우팅하여 NAT Gateway 요금을 제거합니다. 30장. 도메인 4.

**Gateway Load Balancer (GWLB)** — 타사 가상 네트워크 어플라이언스(방화벽, IDS/IPS)를 트래픽 흐름에 인라인으로 삽입하기 위한 계층 3 로드 밸런서입니다. 7장. 도메인 1.

**지리적 위치 라우팅(Route 53)** — DNS 쿼리 출처의 지리적 위치에 따라 라우팅합니다. 12장. 도메인 3.

**Global Accelerator** — Anycast를 통해 가장 가까운 AWS 엣지로 트래픽을 라우팅하여 동적 애플리케이션의 지연 시간을 개선합니다. 25장. 도메인 3.

**Glue (AWS)** — 서버리스 ETL입니다. Glue 크롤러가 스키마를 검색하고, Glue 작업이 데이터를 변환하며, Data Catalog가 메타데이터를 저장합니다. 26장. 도메인 3.

**GSI (Global Secondary Index)** — 다른 파티션 키와 선택적 정렬 키를 가진 DynamoDB 테이블의 대체 인덱스입니다. 유연한 쿼리 패턴을 가능하게 합니다. 9장. 도메인 3.

**GuardDuty** — CloudTrail, VPC 흐름 로그, DNS 로그에 ML을 사용하여 비정상 활동을 탐지하는 위협 탐지 서비스입니다. 17장. 도메인 1.

---

## H

**상태 확인(Route 53)** — 엔드포인트 가용성을 모니터링합니다. 실패한 상태 확인은 장애 조치 라우팅을 트리거합니다. 12장. 도메인 2.

**핫 파티션(DynamoDB)** — 많은 요청이 동일한 파티션 키를 공유하여 불균형한 트래픽을 받는 파티션입니다. 9장. 도메인 3.

## I

**IAM (Identity and Access Management)** — AWS 계정의 인증과 권한 부여를 제어합니다. 사용자, 그룹, 역할, 정책. 3장, 14장. 도메인 1.

**IAM 역할** — 임시 자격 증명을 가진 IAM 자격으로, 서비스, 사용자, 또는 다른 계정이 수임합니다. 3장, 14장. 도메인 1.

**멱등성** — 한 번 호출하든 여러 번 호출하든 동일한 결과를 내는 작업의 속성입니다. 분산 시스템(환불, 결제, 주문 처리)에 중요합니다. 32장. 교차 도메인.

**멱등성 키** — 작업의 고유 식별자로, 중복 처리를 방지하기 위해 실행 전에 확인합니다. 32장. 교차 도메인.

**인터페이스 엔드포인트(PrivateLink)** — 대부분의 AWS 서비스를 위한 VPC 엔드포인트입니다. 시간당 + GB당 요금이 부과됩니다. 인터넷이나 NAT 없이 프라이빗 연결을 제공합니다. 30장. 도메인 4.

**Internet Gateway (IGW)** — 퍼블릭 서브넷의 인스턴스가 인터넷과 통신할 수 있게 합니다. 서브넷의 라우팅 테이블에 IGW로의 경로가 있어야 합니다. 11장. 도메인 3.

**"상황에 따라 다름"** — 대부분의 아키텍처 질문에 대한 정직한 답변으로, 항상 완성되어야 합니다: "접근 패턴 / 규모 / 장애 결과 / 비용 제약에 따라 다릅니다." 33장. 교차 도메인.

## K

**Kinesis Data Firehose** — Amazon Data Firehose의 이전 이름: 스트리밍 데이터를 S3, Redshift, OpenSearch로 관리형 전송합니다. 소비자 관리가 없습니다. 오래된 시험 문제는 여전히 이전 이름을 사용할 수 있습니다. 26장. 도메인 3.

**Kinesis Data Streams** — 실시간 순서가 보장된 이벤트 스트림입니다. 내구성이 있고, 보존 기간 내(기본 24시간, 최대 365일) 재생 가능합니다. 샤드로 측정됩니다. 26장. 도메인 3.

**KMS (Key Management Service)** — 저장 데이터 암호화를 위한 암호화 키를 생성, 저장, 제어합니다. 16장. 도메인 1.

## L

**Lambda** — 이벤트에 의해 트리거되는 서버리스 함수입니다. 호출당, ms당 지불합니다. 최대 15분 실행 시간. 20장. 도메인 2, 3, 4.

**Lambda@Edge** — CloudFront 엣지 로케이션에서 실행되어 요청과 응답을 수정하는 Lambda 함수입니다. 13장. 도메인 3.

**AWS Lake Formation** — S3와 Glue Data Catalog 위에 있는 중앙 집중식 데이터 레이크 접근 제어 계층입니다. 테이블, 열, 행 수준에서 세분화된 권한을 제공합니다. 보안 데이터 레이크 설정을 단순화합니다. 26장. 도메인 3.

**지연 시간 기반 라우팅(Route 53)** — DNS 쿼리를 측정된 지연 시간이 가장 낮은 AWS 리전으로 라우팅합니다. 12장. 도메인 3.

**시작 템플릿** — Auto Scaling 그룹을 위한 EC2 인스턴스 구성을 지정하는 버전 관리된 템플릿입니다. 7장. 도메인 3.

**최소 권한** — IAM 모범 사례: 필요한 권한만 부여하고, 그 이상은 부여하지 않습니다. 3장. 도메인 1.

**수명 주기 정책(S3)** — 수명에 따라 객체를 더 저렴한 스토리지 클래스로 자동 전환하거나 삭제하는 규칙입니다. 23장. 도메인 4.

**LSI (Local Secondary Index)** — 동일한 파티션 키를 사용하지만 다른 정렬 키를 사용하는 DynamoDB 테이블의 대체 인덱스입니다. 테이블 생성 시 만들어야 합니다. 9장. 도메인 3.

## M

**Amazon Macie** — S3에서 민감한 데이터(PII)를 ML 기반으로 검색하고 노출 위험을 표시합니다. GuardDuty는 동작을 감시하고, Macie는 저장된 것을 감사합니다. 17장. 도메인 1.

**Memcached** — 단순한 멀티스레드 인메모리 캐싱 엔진입니다. 영속성도, 데이터 구조도 없습니다. 멀티스레딩이 기능보다 특별히 필요한 경우가 아니라면 Redis를 사용하십시오. 10장. 도메인 3.

**Amazon MemoryDB for Redis** — 내구성 있는 Redis 호환 인메모리 기본 데이터베이스입니다. ElastiCache와 달리 MemoryDB는 Multi-AZ 트랜잭션 로그에 기록하여 데이터 내구성을 보장합니다. Redis API 호환성이 필요하면서 데이터 손실이 허용되지 않을 때 사용합니다. 10장. 도메인 3.

**MGN (AWS Application Migration Service)** — 리호스트/리프트 앤 시프트: 서버 전체를 AWS로 블록 수준 복제하고, 테스트 실행한 다음 네이티브 EC2 인스턴스로 전환합니다. DataSync는 파일을 옮기고, DMS는 데이터베이스를 옮기며, MGN은 서버를 옮깁니다. 25장. 도메인 3.

**Amazon MQ** — 표준 프로토콜(AMQP, MQTT, STOMP)을 사용하는 관리형 ActiveMQ/RabbitMQ 브로커입니다. 코드 변경 없이 기존 브로커 워크로드를 리프트 앤 시프트하기 위한 것입니다. 신규 메시징 → SQS/SNS. 19장. 도메인 2.

**Multi-AZ (RDS)** — 자동 장애 조치를 갖춘 다른 AZ의 동기식 스탠바이 복제본입니다. RPO ~0, RTO ~60초. 읽기 확장이 아니라 고가용성을 위한 것입니다. 8장, 18장. 도메인 2.

**Multi-Region** — 지리적 이중화와 글로벌 성능을 위해 여러 AWS 리전에 애플리케이션 구성 요소를 배포하는 것입니다. 복잡성과 비용이 더 높습니다. 18장. 도메인 2.

## N

**Network Load Balancer (NLB)** — 계층 4(TCP/UDP/TLS) 로드 밸런서: 초당 수백만 건의 요청, AZ당 정적 IP, 소스 IP 보존. HTTP 인식 없음 — 그것은 ALB의 역할입니다. 7장. 도메인 3.

**NACL (Network Access Control List)** — 서브넷 수준의 상태 비저장 방화벽입니다. 인바운드와 아웃바운드 규칙이 모두 필요합니다. 규칙은 숫자 순서로 평가됩니다. 15장. 도메인 1.

**NAT Gateway** — 프라이빗 서브넷의 인스턴스가 인터넷으로 아웃바운드 연결을 할 수 있게 합니다. 처리된 GB당 $0.045가 부과됩니다. 11장, 30장. 도메인 4.

## O

**객체(S3)** — S3에 저장된 파일입니다. 키(이름), 값(데이터), 메타데이터로 구성됩니다. 최대 크기 5TB. 5장. 도메인 3.

**온디맨드 용량(DynamoDB)** — 요청당 지불 모드입니다. 프로비저닝보다 요청당 비용이 비싸지만 용량 계획이 필요 없습니다. 29장. 도메인 4.

**온디맨드 인스턴스(EC2)** — 약정 없이 시간당 지불합니다. 최대 유연성, 최대 가격. 27장. 도메인 4.

**AWS Outposts** — 고객의 자체 데이터 센터나 코로케이션 시설에 설치되는 완전 관리형 AWS 하드웨어 랙입니다. 퍼블릭 클라우드와 동일한 AWS 서비스, API, 도구를 온프레미스에서 실행합니다. AWS가 설치와 패치를 관리하고, 고객이 랙 공간과 전력을 제공합니다. 데이터 레지던시, 낮은 지연 시간의 온프레미스 워크로드, 또는 연결이 끊긴 시나리오용입니다. 2장. 도메인 4.

## P

**파티션 키(DynamoDB)** — 어느 파티션이 항목을 저장할지 결정하는 기본 키 구성 요소입니다. 고른 분포를 위해 높은 카디널리티의 키를 선택하십시오. 9장. 도메인 3.

**권한 경계** — 다른 정책이 더 많이 부여하더라도 IAM 자격이 가질 수 있는 최대 권한을 설정하는 IAM 정책입니다. 14장. 도메인 1.

**배치 그룹** — 지연 시간을 최소화하거나(클러스터) 가용성을 최대화하기 위해(스프레드) EC2 인스턴스의 물리적 배치를 제어합니다. 4장. 도메인 3.

**PrivateLink** — AWS에 호스팅된 서비스에 대한 프라이빗 엔드포인트를 만들기 위한 AWS 서비스로, 인터페이스 엔드포인트를 통해 접근할 수 있습니다. 30장. 도메인 1.

**프로비저닝된 동시성(Lambda)** — 콜드 스타트 지연을 제거하는 사전 초기화된 실행 환경입니다. 20장. 도메인 3.

**프로비저닝된 용량(DynamoDB)** — 초당 용량 단위로 측정되는 사전 할당된 읽기 및 쓰기 처리량입니다. 예측 가능한 트래픽의 경우 온디맨드보다 저렴합니다. 9장, 29장. 도메인 4.

## Q

**Amazon QuickSight** — 관리형 비즈니스 인텔리전스 및 데이터 시각화 서비스입니다. 데이터를 캐싱하여 빠른 대시보드 렌더링을 제공하는 SPICE(Super-fast, Parallel, In-memory Calculation Engine)를 사용합니다. Athena, S3, Redshift, RDS 및 기타 AWS 데이터 소스에 연결됩니다. 관리할 BI 서버가 없습니다. 26장. 도메인 3.

## R

**RDS (Relational Database Service)** — 관리형 관계형 데이터베이스입니다. 백업, 패치, 장애 조치를 처리합니다. 8장. 도메인 3.

**RDS Proxy** — Lambda/애플리케이션과 RDS 사이의 연결 풀을 관리하여 연결 고갈을 방지합니다. 8장. 도메인 3.

**읽기 전용 복제본(RDS)** — 읽기 확장을 위한 데이터베이스의 비동기식 복사본입니다. 자동 장애 조치를 제공하지 않습니다. 8장, 24장. 도메인 3.

**Redis** — 캐싱, 세션 관리, 실시간 리더보드, 게시/구독에 사용되는 인메모리 데이터 구조 저장소입니다. 10장. 도메인 3.

**Reserved Instance (EC2)** — 할인을 대가로 특정 리전에서 특정 인스턴스 유형을 1년 또는 3년간 사용하겠다는 약정입니다. 27장. 도메인 4.

**Route 53** — AWS DNS 서비스이자 도메인 등록 대행 서비스입니다. 여러 라우팅 정책을 지원합니다. 12장. 도메인 2, 3.

**RPO (Recovery Point Objective)** — 시간으로 측정한 허용 가능한 최대 데이터 손실입니다. "얼마나 많은 데이터를 잃어도 괜찮은가?" 18장. 도메인 2.

**RTO (Recovery Time Objective)** — 장애 후 서비스를 복원하는 데 허용 가능한 최대 시간입니다. "얼마나 오래 다운되어도 괜찮은가?" 18장. 도메인 2.

**런북** — 시스템 운영, 특히 인시던트 대응을 위한 단계별 지침입니다. "새벽 3시에 누군가는 무엇을 하는가?" 32장. 교차 도메인.

## S

**S3 Intelligent-Tiering** — 접근 패턴에 따라 S3 객체를 접근 계층 간에 자동으로 이동합니다. 검색 수수료가 없습니다. 23장. 도메인 4.

**S3 Select** — SQL 표현식을 사용하여 S3 객체 콘텐츠의 일부를 검색해 데이터 전송을 줄입니다. 레거시: 2024년 중반부터 신규 고객에게 제공되지 않음 — Athena가 이제 S3에서 데이터를 필터링하고 쿼리하는 기본 경로입니다. 한때 권장 대안이었던 S3 Object Lambda 자체도 레거시입니다(2025년 11월 신규 고객에게 중단, 기존 워크로드는 계속 작동). 30장. 도메인 4.

**Savings Plan** — 할인을 대가로 시간당 지출 금액을 약정하는 유연한 가격 모델입니다. Reserved Instances보다 유연합니다. 27장. 도메인 4.

**SCP (Service Control Policy)** — OU의 계정에 사용 가능한 최대 권한을 제한하는 AWS Organizations 정책입니다. 14장. 도메인 1.

**Secrets Manager** — 비밀(데이터베이스 비밀번호, API 키)을 저장하고 자동으로 회전합니다. 16장. 도메인 1.

**보안 그룹** — 인스턴스 수준의 상태 저장 가상 방화벽입니다. 허용 규칙만 있으며, 반환 트래픽은 자동입니다. 15장. 도메인 1.

**샤드(Kinesis)** — Kinesis Data Streams의 기본 처리량 단위: 쓰기 1MB/s, 읽기 2MB/s. 26장. 도메인 3.

**공동 책임 모델** — AWS는 클라우드 *의* 보안(인프라)에 책임이 있고, 여러분은 클라우드 *내* 보안(데이터, 구성, 접근)에 책임이 있습니다. 1장. 도메인 1.

**Shield** — DDoS 방어입니다. Standard: 무료, 자동. Advanced: 유료, DRT 지원 및 재정적 보호 포함. 17장. 도메인 1.

**Snow Family** — 오프라인 대량 데이터 전송을 위한 물리적 디바이스(Snowball Edge: 80TB) — 고속도로를 운전하는 대신 화물 항공편을 전세 내는 것. 레거시(2026): Snowmobile과 Snowcone 중단, Snow 디바이스는 2025년 11월 신규 고객에게 중단(AWS는 DataSync와 Data Transfer Terminals를 안내), 그러나 SAA-C03 시험은 여전히 "수 주간의 전송, 제한된 대역폭"에 대해 Snowball을 기대합니다. 25장. 도메인 3.

**SNS (Simple Notification Service)** — 게시/구독 메시징입니다. 모든 구독자에게 메시지를 동시에 푸시합니다. 팬아웃 패턴. 19장. 도메인 2.

**정렬 키(DynamoDB)** — 기본 키의 선택적 두 번째 구성 요소입니다. 파티션 내 범위 쿼리를 가능하게 합니다. 9장. 도메인 3.

**Spot 인스턴스** — 여분 용량을 60~90% 할인된 가격에 사용하는 EC2 인스턴스입니다. 2분 통지로 중단될 수 있습니다. 내결함성 워크로드 전용입니다. 27장. 도메인 4.

**SQS (Simple Queue Service)** — 관리형 메시지 대기열입니다. 생산자를 소비자에서 분리합니다. 표준(최소 1회) 및 FIFO(정확히 1회) 대기열. 19장. 도메인 2.

**Step Functions** — 서버리스 워크플로 오케스트레이션 서비스입니다. AWS 서비스를 조정하기 위한 상태 머신. 22장. 도메인 2.

**AWS Storage Gateway** — 온프레미스와 클라우드 스토리지 사이의 다리: NFS/SMB(File), iSCSI(Volume), 또는 가상 테이프(Tape) 인터페이스를 로컬에 제공하면서 데이터는 S3, Glacier, 또는 EBS 스냅샷으로 유지합니다. 6장. 도메인 3.

## T

**대상 추적 확장** — 대상 지표 값(예: 60% CPU 사용률)을 유지하기 위해 용량을 조정하는 Auto Scaling 정책입니다. 7장. 도메인 2.

**AWS Transfer Family** — S3 또는 EFS를 백업으로 사용하는 관리형 SFTP/FTPS/FTP 엔드포인트입니다. 파트너는 기존 SFTP 클라이언트를 유지하고, 파일은 여러분의 버킷에 직접 저장됩니다. 25장. 도메인 3.

**Transit Gateway** — 중앙 게이트웨이를 통해 여러 VPC와 온프레미스 네트워크를 연결하는 허브 앤 스포크 네트워크 토폴로지입니다. 25장. 도메인 3.

**TTL (Time to Live)** — 그 이후 DynamoDB가 항목을 자동으로 삭제하는 타임스탬프입니다. DNS(리졸버가 레코드를 캐싱하는 기간)와 캐싱(캐시된 값이 유효한 기간)에서도 사용됩니다. 9장, 12장. 도메인 3.

---

## V

**VIF (Virtual Interface)** — AWS Direct Connect와 함께 사용되는 논리적 연결입니다. 퍼블릭 VIF는 AWS 퍼블릭 엔드포인트에 접근하고, 프라이빗 VIF는 VPC 리소스에 접근합니다. 25장. 도메인 3.

**가시성 제한 시간(SQS)** — 수신된 메시지가 다른 소비자로부터 숨겨지는 기간입니다. 다른 소비자가 동일한 메시지를 보지 않고 처리할 수 있게 합니다. 19장. 도메인 2.

**VPC (Virtual Private Cloud)** — AWS의 격리된 가상 네트워크입니다. 서브넷, 라우팅 테이블, 게이트웨이를 포함합니다. 11장. 도메인 1.

**VPC 엔드포인트** — AWS 프라이빗 네트워크를 통해 VPC 리소스를 AWS 서비스에 연결합니다. 게이트웨이(무료, S3/DynamoDB) 및 인터페이스(유료, 대부분의 다른 서비스). 30장. 도메인 1, 4.

**VPC 흐름 로그** — VPC의 네트워크 인터페이스로/에서 오가는 IP 트래픽에 대한 정보를 캡처합니다. GuardDuty와 네트워크 문제 해결에 사용됩니다. 17장. 도메인 1.

**VPC 피어링** — 두 VPC 간의 네트워크 연결로, 프라이빗 IP 주소를 사용하여 트래픽이 그 사이를 라우팅할 수 있게 합니다. 11장. 도메인 3.

---

## W

**WAF (Web Application Firewall)** — 규칙(IP 차단, SQL 인젝션, 속도 제한)을 사용하여 HTTP/HTTPS 트래픽을 필터링합니다. CloudFront, ALB, 또는 API Gateway에 연결됩니다. 17장. 도메인 1.

**AWS Wavelength** — 5G 통신 사업자의 네트워크 내 무선 엣지에 배포되는 AWS 인프라입니다. 모바일 디바이스에 한 자릿수 밀리초 지연 시간을 가능하게 합니다. 모바일 AR/VR, 실시간 게임, 자율주행 차량 텔레메트리, 5G 엣지의 라이브 비디오용입니다. Wavelength Zone은 통신 네트워크 내 AWS 리전의 확장입니다. 2장. 도메인 3.

**Well-Architected Framework** — AWS의 여섯 가지 기둥 평가 프레임워크: 운영 우수성, 보안, 안정성, 성능 효율성, 비용 최적화, 지속 가능성. 31장. 교차 도메인.

**가중치 라우팅(Route 53)** — 가중치에 따라 DNS 쿼리를 엔드포인트에 분산합니다. 블루-그린 배포와 A/B 테스트에 사용됩니다. 12장. 도메인 3.

**라이트 스루 캐싱** — 데이터베이스가 업데이트될 때마다 캐시를 업데이트합니다. 데이터는 항상 일관되지만 캐시가 다시 읽히지 않는 많은 항목을 보유할 수 있습니다. 10장. 도메인 3.

# Sobre o Autor

AI(2)M(2)IA é um pseudônimo para um experimento contínuo em escrita assistida por inteligência artificial — um livro de cada vez, com total transparência.

Cada título publicado sob este nome foi criado com assistência de IA para geração de narrativa, refinamento editorial, arte da capa e preparação de e-book. Os mundos, personagens, temas e decisões estruturais são dirigidos por humanos. O processo é divulgado em cada volume.

O experimento não é sobre se a IA pode substituir os escritores. É sobre se o trabalho assistido por IA pode fazer escolhas reais — premissas com peso, estruturas que significam algo, personagens que não se resolvem de forma limpa. O trabalho é a evidência. Os leitores são o júri.

*AI(2)M(2)IA. Um livro impossível de cada vez.*

# Приложение C: Реестр концепций

Каждая ключевая концепция, введённая в книге, сопоставлена с её главой, использованной аналогией и областью SAA-C03, в которой она встречается.

Используйте это как учебный указатель: если перед экзаменом вы нечётко понимаете концепцию, найдите её здесь и вернитесь к её главе для контекста.

---

## A

**ACU (Aurora Capacity Unit)** — единица измерения мощности Aurora Serverless v2. Масштабируется автоматически. Глава 24. Область 3.

**Alarm (CloudWatch)** — правило, срабатывающее, когда метрика пересекает порог, запуская уведомление или действие авто-масштабирования. Глава 7. Область 2.

**ALB (Application Load Balancer)** — балансировщик нагрузки уровня 7, маршрутизирующий HTTP/HTTPS-трафик на основе правил пути и хоста. Глава 7. Область 2.

**AMI (Amazon Machine Image)** — шаблон, содержащий ОС, программное обеспечение и конфигурацию для EC2-инстанса. Глава 4. Область 3.

**Мышление архитектора** — задавать «что ломается первым, как мы узнаем и что делает кто-то в 3 ночи?» вместо только «как это работает?» Главы 32, 34. Кросс-доменная.

**Architecture Decision Record (ADR)** — короткий документ, фиксирующий решение, его альтернативы, обоснование и что вызвало бы пересмотр. Глава 32. Кросс-доменная.

**Архитектурный анализ** — структурированный процесс, охватывающий: ограничения → неизвестности → варианты → режимы сбоев → мониторинг → runbooks. Глава 32. Кросс-доменная.

**Athena** — бессерверный сервис SQL-запросов для данных в S3. Платите за ТБ сканирования. Лучше всего с столбчатыми форматами Parquet/ORC. Глава 26. Область 3.

**Auto Scaling Group (ASG)** — группа EC2-инстансов, управляемых совместно, автоматически заменяющая нездоровые инстансы и масштабирующаяся по нагрузке. Глава 7. Области 2, 3.

**Availability Zone (AZ)** — один или несколько физически отдельных дата-центров в регионе, связанных низкозадержными соединениями. Глава 2. Область 2.

## B

**Бакет (S3)** — контейнер для объектов S3. Бакеты имеют уникальные глобальные имена и привязаны к конкретному региону. Глава 5. Область 3.

**Политика бакета** — ресурсная политика, прикреплённая к S3-бакету, управляющая доступом для IAM-принципалов и внешних аккаунтов. Глава 5. Область 1.

## C

**Паттерн cache-aside** — приложение сначала проверяет кэш; при промахе запрашивает базу данных, затем сохраняет результат в кэш. Глава 10. Область 3.

**Частота попаданий в кэш** — процент запросов, обслуживаемых из кэша, а не с источника. Выше — лучше. Глава 13. Область 3.

**CloudFront** — CDN AWS. Кэширует контент на 400+ граничных серверах по всему миру. Снижает задержку и затраты на передачу данных с источника. Глава 13. Области 3, 4.

**CloudTrail** — логирует каждый вызов API AWS: кто, что, когда, откуда. Хранится в S3. Используется для аудита и расследования инцидентов. Область 1.

**CloudWatch** — метрики, логи, оповещения и панели для ресурсов AWS и пользовательских приложений. Упоминается на протяжении всей книги. Все области.

**Холодный старт (Lambda)** — задержка при первом вызове (или после периода бездействия), пока Lambda инициализирует среду выполнения. Используйте provisioned concurrency для устранения. Глава 20. Область 3.

**Compute Savings Plan** — обязательство по сумме почасовых расходов на EC2, применимое к любому типу или размеру инстанса. Глава 27. Область 4.

**Config (AWS)** — отслеживает изменения конфигурации ресурсов AWS с течением времени и оценивает соответствие правилам. Глава 31. Область 1.

**Кросс-AZ передача данных** — трафик между зонами доступности в пределах региона. Тарифицируется по $0,01/ГБ в каждом направлении. Глава 30. Область 4.

**Кросс-региональная репликация** — копирование данных (S3 CRR, Aurora Global, DynamoDB Global Tables) в другой регион. Влечёт затраты на передачу данных. Главы 18, 30. Область 2.

## D

**DAX (DynamoDB Accelerator)** — кэш в памяти специально для DynamoDB. Задержка чтения в микросекунды. Глава 9. Область 3.

**Dead Letter Queue (DLQ)** — очередь, в которую направляются сообщения, неоднократно не прошедшие обработку, предотвращая блокировку очереди. Глава 19. Область 2.

**Dedicated Host** — физический сервер EC2, зарезервированный исключительно для вашего использования. Требуется для определённых программных лицензий. Глава 27. Область 4.

**Глубокая защита** — наслоение нескольких средств управления безопасностью (IAM + группы безопасности + NACL + WAF + GuardDuty), чтобы компрометация одного уровня не раскрывала систему. Глава 33. Область 1.

**Direct Connect** — выделенное частное сетевое соединение из локальной сети в AWS. Более стабильное, чем VPN. Глава 25. Область 3.

**DLQ** — см. Dead Letter Queue.

**DynamoDB** — полностью управляемая NoSQL-база данных с однозначными миллисекундами задержки в любом масштабе. Модель «ключ-значение» и документов. Глава 9. Область 3.

**DynamoDB Auto Scaling** — автоматически регулирует выделенную ёмкость чтения/записи на основе метрик CloudWatch. Глава 29. Область 4.

**DynamoDB Streams** — упорядоченный по времени журнал всех изменений элементов в таблице DynamoDB. Используется с Lambda для событийно-управляемой обработки. Глава 9. Область 2.

## E

**EBS (Elastic Block Store)** — блочное хранилище, подключённое к одному EC2-инстансу. Сохраняется независимо. Типы: gp3, io2, st1. Глава 6. Область 3.

**EC2 (Elastic Compute Cloud)** — виртуальные машины в облаке. Глава 4. Область 3.

**ECS (Elastic Container Service)** — управляемая оркестрация контейнеров. Тип запуска Fargate устраняет управление серверами. Глава 21. Области 2, 3.

**EFS (Elastic File System)** — общая NFS-файловая система, доступная для нескольких EC2-инстансов. Масштабируется автоматически. Глава 6. Область 3.

**EKS (Elastic Kubernetes Service)** — управляемая плоскость управления Kubernetes в AWS. Глава 21. Область 3.

**ElastiCache** — управляемое кэширование в памяти. Redis (богаче функционалом) или Memcached (проще). Глава 10. Область 3.

**Elastic IP** — статический публичный IP-адрес, который можно выделить и повторно связать с EC2-инстансами. Глава 11. Область 3.

**Конвертное шифрование** — паттерн, где данные шифруются ключом данных (DEK), а DEK шифруется мастер-ключом (CMK в KMS). Глава 16. Область 1.

**EventBridge** — шина событий для маршрутизации событий от сервисов AWS, SaaS-партнёров и пользовательских источников к целям. Поддерживает запланированные правила. Глава 22. Область 2.

**Явный запрет** — IAM-правило запрета, которое нельзя переопределить никаким разрешением. Имеет приоритет над всеми разрешениями. Глава 3. Область 1.

## F

**Failover routing (Route 53)** — маршрутизирует трафик к вторичной конечной точке при сбое основной на проверках работоспособности. Глава 12. Область 2.

**Fargate** — бессерверный вычислительный движок для ECS и EKS. Нет EC2-инстансов для управления. Глава 21. Область 3.

**Паттерн веерной рассылки** — один топик SNS доставляет то же сообщение нескольким очередям SQS одновременно. Глава 19. Область 2.

**FIFO-очередь (SQS)** — точно однократная обработка, строгая упорядоченность. Более низкая пропускная способность, чем у стандартных очередей. Глава 19. Область 2.

**Режим сбоя** — конкретный способ, которым система может сломаться. Определение режимов сбоев до production — суть архитектурного анализа. Глава 32. Кросс-доменная.

## G

**Gateway Endpoint** — бесплатный тип VPC-эндпоинта для S3 и DynamoDB. Маршрутизирует трафик через частную сеть AWS, устраняя плату за NAT Gateway. Глава 30. Область 4.

**Geolocation routing (Route 53)** — маршрутизирует на основе географического местоположения источника DNS-запроса. Глава 12. Область 3.

**Global Accelerator** — маршрутизирует трафик к ближайшему граничному серверу AWS через Anycast, улучшая задержку для динамических приложений. Глава 25. Область 3.

**Glue (AWS)** — бессерверный ETL. Glue Crawlers обнаруживают схему; Glue Jobs преобразуют данные; Data Catalog хранит метаданные. Глава 26. Область 3.

**GSI (Global Secondary Index)** — альтернативный индекс в таблице DynamoDB с другим partition key и опциональным sort key. Обеспечивает гибкие паттерны запросов. Глава 9. Область 3.

**GuardDuty** — сервис обнаружения угроз, использующий ML на CloudTrail, VPC Flow Logs и DNS-логах для обнаружения необычной активности. Глава 17. Область 1.

## H

**Проверка работоспособности (Route 53)** — мониторинг доступности конечной точки. Неудавшиеся проверки запускают failover-маршрутизацию. Глава 12. Область 2.

**Горячая партиция (DynamoDB)** — партиция, получающая непропорциональный трафик, потому что многие запросы разделяют один и тот же partition key. Глава 9. Область 3.

## I

**IAM (Identity and Access Management)** — управляет аутентификацией и авторизацией для AWS-аккаунтов. Пользователи, группы, роли, политики. Главы 3, 14. Область 1.

**IAM-роль** — IAM-идентификатор с временными учётными данными, принимаемый сервисами, пользователями или другими аккаунтами. Главы 3, 14. Область 1.

**Идемпотентность** — свойство операции, которая производит одинаковый результат при однократном или многократном вызове. Критично для распределённых систем (возвраты, платежи, обработка заказов). Глава 32. Кросс-доменная.

**Ключ идемпотентности** — уникальный идентификатор для операции, проверяемый перед выполнением для предотвращения дублирующейся обработки. Глава 32. Кросс-доменная.

**Interface Endpoint (PrivateLink)** — VPC-эндпоинт для большинства сервисов AWS. Платный за час + за ГБ. Обеспечивает частное подключение без интернета или NAT. Глава 30. Область 4.

**Internet Gateway (IGW)** — позволяет инстансам в публичных подсетях взаимодействовать с интернетом. Требует, чтобы в таблице маршрутизации подсети был маршрут к IGW. Глава 11. Область 3.

**«Зависит от...»** — честный ответ на большинство архитектурных вопросов, который всегда нужно дополнить: «зависит от паттерна доступа / масштаба / последствия сбоя / ограничения по стоимости». Глава 33. Кросс-доменная.

## K

**Kinesis Data Firehose** — управляемая доставка потоковых данных в S3, Redshift, OpenSearch. Без управления потребителями. Глава 26. Область 3.

**Kinesis Data Streams** — упорядоченный поток событий в реальном времени. Надёжный, воспроизводимый. Измеряется в шардах. Глава 26. Область 3.

**KMS (Key Management Service)** — создаёт, хранит и управляет криптографическими ключами для шифрования в покое. Глава 16. Область 1.

---

## L

**Lambda** — бессерверные функции, запускаемые событиями. Платите за вызов и за мс. Максимум 15 минут продолжительности. Глава 20. Области 2, 3, 4.

**Lambda@Edge** — Lambda-функции, выполняемые на граничных серверах CloudFront, изменяющие запросы и ответы. Глава 13. Область 3.

**Latency-based routing (Route 53)** — маршрутизирует DNS-запросы в регион AWS с наименьшей измеренной задержкой. Глава 12. Область 3.

**Шаблон запуска (Launch template)** — версионированный шаблон, задающий конфигурацию EC2-инстанса для Auto Scaling Groups. Глава 7. Область 3.

**Минимальные привилегии** — лучшая практика IAM: предоставляйте только необходимые разрешения. Глава 3. Область 1.

**Политика жизненного цикла (S3)** — правила, автоматически переводящие объекты в более дешёвые классы хранилища или удаляющие их по возрасту. Глава 23. Область 4.

**LSI (Local Secondary Index)** — альтернативный индекс в таблице DynamoDB с тем же partition key, но другим sort key. Должен быть создан при создании таблицы. Глава 9. Область 3.

## M

**Memcached** — простой, многопоточный движок кэширования в памяти. Без постоянства, без структур данных. Используйте Redis, если специально не нужна многопоточность ценой функционала. Глава 10. Область 3.

**Multi-AZ (RDS)** — синхронная резервная реплика в другой AZ с автоматическим переключением. RPO ~0, RTO ~60 секунд. Для высокой доступности, а не масштабирования чтения. Главы 8, 18. Область 2.

**Multi-Region** — развёртывание компонентов приложения в нескольких регионах AWS для географической избыточности и глобальной производительности. Более высокая сложность и стоимость. Глава 18. Область 2.

---

## N

**NACL (Network Access Control List)** — stateless-брандмауэр на уровне подсети. Требует правил и для входящего, и для исходящего. Правила вычисляются в числовом порядке. Глава 15. Область 1.

**NAT Gateway** — позволяет инстансам в частных подсетях устанавливать исходящие соединения с интернетом. Тарифицируется по $0,045/ГБ обработки. Главы 11, 30. Область 4.

---

## O

**Объект (S3)** — файл, хранящийся в S3. Состоит из ключа (имя), значения (данные) и метаданных. Максимальный размер 5 ТБ. Глава 5. Область 3.

**On-Demand мощность (DynamoDB)** — режим оплаты за запрос. Дороже за запрос, чем provisioned, но без планирования мощности. Глава 29. Область 4.

**On-Demand инстансы (EC2)** — оплата за час без обязательства. Максимальная гибкость, максимальная цена. Глава 27. Область 4.

---

## P

**Partition key (DynamoDB)** — компонент первичного ключа, определяющий, в какой партиции хранится элемент. Выбирайте ключ с высокой кардинальностью для равномерного распределения. Глава 9. Область 3.

**Граница разрешений** — IAM-политика, устанавливающая максимальные разрешения, которые может иметь IAM-идентификатор, даже если другие политики предоставляют больше. Глава 14. Область 1.

**Группа размещения** — управляет физическим размещением EC2-инстансов для минимизации задержки (кластер) или максимизации доступности (распределение). Глава 4. Область 3.

**PrivateLink** — сервис AWS для создания частных эндпоинтов к сервисам, размещённым в AWS, доступных через Interface Endpoints. Глава 30. Область 1.

**Provisioned concurrency (Lambda)** — предварительно инициализированные среды выполнения, устраняющие задержки холодного старта. Глава 20. Область 3.

**Provisioned мощность (DynamoDB)** — предварительно выделенная пропускная способность чтения/записи, измеряемая в единицах мощности в секунду. Дешевле on-demand для предсказуемого трафика. Главы 9, 29. Область 4.

---

## R

**RDS (Relational Database Service)** — управляемые реляционные базы данных. Управляет резервными копиями, обновлением патчей, переключением. Глава 8. Область 3.

**RDS Proxy** — управляет пулом соединений между Lambda/приложением и RDS, предотвращая исчерпание соединений. Глава 8. Область 3.

**Реплика для чтения (RDS)** — асинхронная копия базы данных для масштабирования чтения. НЕ обеспечивает автоматическое переключение. Главы 8, 24. Область 3.

**Redis** — хранилище структур данных в памяти, используемое для кэширования, управления сессиями, таблиц лидеров в реальном времени, pub/sub. Глава 10. Область 3.

**Reserved Instance (EC2)** — обязательство использовать конкретный тип инстанса в конкретном регионе на 1 или 3 года в обмен на скидку. Глава 27. Область 4.

**Route 53** — DNS-сервис и регистратор доменов AWS. Поддерживает множество политик маршрутизации. Глава 12. Области 2, 3.

**RPO (Recovery Point Objective)** — максимально допустимая потеря данных, измеряемая во времени. «Сколько данных мы можем позволить себе потерять?» Глава 18. Область 2.

**RTO (Recovery Time Objective)** — максимально допустимое время восстановления сервиса после сбоя. «Как долго мы можем быть недоступны?» Глава 18. Область 2.

**Runbook** — пошаговые инструкции по эксплуатации системы, специально для реагирования на инциденты. «Что делает кто-то в 3 ночи?» Глава 32. Кросс-доменная.

---

## S

**S3 Intelligent-Tiering** — автоматически перемещает объекты S3 между уровнями доступа на основе паттернов доступа. Без платы за извлечение. Глава 23. Область 4.

**S3 Select** — извлекает подмножество содержимого объекта S3 с использованием SQL-выражений, снижая передачу данных. Глава 30. Область 4.

**Savings Plan** — гибкая модель ценообразования, обязывающая к сумме почасовых расходов в обмен на скидку. Более гибкий, чем Reserved Instances. Глава 27. Область 4.

**SCP (Service Control Policy)** — политика AWS Organizations, ограничивающая максимальные разрешения, доступные аккаунтам в OU. Глава 14. Область 1.

**Secrets Manager** — хранит и автоматически ротирует секреты (пароли баз данных, API-ключи). Глава 16. Область 1.

**Группа безопасности** — stateful виртуальный брандмауэр на уровне инстанса. Только разрешающие правила; обратный трафик автоматический. Глава 15. Область 1.

**Шард (Kinesis)** — базовая единица пропускной способности в Kinesis Data Streams: 1 МБ/с запись, 2 МБ/с чтение. Глава 26. Область 3.

**Модель разделённой ответственности** — AWS несёт ответственность за безопасность *облака* (инфраструктура); вы несёте ответственность за безопасность *в* облаке (данные, конфигурация, доступ). Глава 1. Область 1.

**Shield** — защита от DDoS. Standard: бесплатный, автоматический. Advanced: платный, с поддержкой DRT и финансовой защитой. Глава 17. Область 1.

**SNS (Simple Notification Service)** — pub/sub-обмен сообщениями. Отправляет сообщения всем подписчикам одновременно. Паттерн веерной рассылки. Глава 19. Область 2.

**Sort key (DynamoDB)** — опциональный второй компонент первичного ключа. Обеспечивает диапазонные запросы внутри партиции. Глава 9. Область 3.

**Spot Instances** — EC2-инстансы, использующие свободные мощности со скидкой 60–90%. Могут быть прерваны с 2-минутным предупреждением. Только для отказоустойчивых нагрузок. Глава 27. Область 4.

**SQS (Simple Queue Service)** — управляемая очередь сообщений. Развязывает производителей от потребителей. Стандартные (не менее одного раза) и FIFO (точно однократно) очереди. Глава 19. Область 2.

**Step Functions** — бессерверный сервис оркестрации рабочих процессов. Машины состояний для координации сервисов AWS. Глава 22. Область 2.

---

## T

**Масштабирование на основе целевого отслеживания** — политика Auto Scaling, регулирующая мощность для поддержания целевого значения метрики (например, 60% использование CPU). Глава 7. Область 2.

**Transit Gateway** — сетевая топология «хаб и спица», соединяющая несколько VPC и локальных сетей через центральный шлюз. Глава 25. Область 3.

**TTL (Time to Live)** — временна́я метка, после которой DynamoDB автоматически удаляет элемент. Также используется в DNS (как долго резолверы кэшируют запись) и в кэшировании (как долго кэшированное значение действительно). Главы 9, 12. Область 3.

---

## V

**VIF (Virtual Interface)** — логическое соединение, используемое с AWS Direct Connect. Public VIF получает доступ к публичным конечным точкам AWS; Private VIF получает доступ к ресурсам VPC. Глава 25. Область 3.

**Таймаут видимости (SQS)** — период, в течение которого полученное сообщение скрыто от других потребителей. Позволяет обрабатывать без того, чтобы другие потребители видели то же сообщение. Глава 19. Область 2.

**VPC (Virtual Private Cloud)** — изолированная виртуальная сеть в AWS. Содержит подсети, таблицы маршрутизации и шлюзы. Глава 11. Область 1.

**VPC Endpoint** — соединяет ресурсы VPC с сервисами AWS через частную сеть AWS. Gateway (бесплатно, S3/DynamoDB) и Interface (платный, большинство других сервисов). Глава 30. Области 1, 4.

**VPC Flow Logs** — захватывает информацию об IP-трафике к/от сетевых интерфейсов в VPC. Используется GuardDuty и для диагностики сети. Глава 17. Область 1.

**Пиринг VPC** — сетевое соединение между двумя VPC, обеспечивающее маршрутизацию трафика между ними с использованием частных IP-адресов. Глава 11. Область 3.

---

## W

**WAF (Web Application Firewall)** — фильтрует HTTP/HTTPS-трафик с использованием правил (блокировка IP, SQL-инъекции, ограничение скорости). Подключается к CloudFront, ALB или API Gateway. Глава 17. Область 1.

**Well-Architected Framework** — шестистолпный оценочный фреймворк AWS: Операционное совершенство, Безопасность, Надёжность, Эффективность производительности, Оптимизация затрат, Устойчивость. Глава 31. Кросс-доменная.

**Weighted routing (Route 53)** — распределяет DNS-запросы между конечными точками по весу. Используется для сине-зелёных развёртываний и A/B-тестирования. Глава 12. Область 3.

**Write-through кэширование** — обновляет кэш при каждом обновлении базы данных. Данные всегда согласованы, но кэш может содержать много элементов, которые никогда не перечитываются. Глава 10. Область 3.

# Об авторе

AI(2)M(2)IA — псевдоним для текущего эксперимента по написанию книг с помощью искусственного интеллекта — по одной книге за раз, с полной прозрачностью.

Каждое произведение, опубликованное под этим именем, было создано с использованием искусственного интеллекта для генерации нарратива, редакционной доработки, создания обложек и подготовки электронных книг. Миры, персонажи, темы и структурные решения определяются человеком. Процесс раскрывается в каждом томе.

Эксперимент не о том, может ли ИИ заменить писателей. Он о том, может ли работа с помощью ИИ делать реальный выбор — предпосылки с весом, структуры, которые что-то значат, персонажи, не разрешающиеся однозначно. Работа — это доказательство. Читатели — судьи.

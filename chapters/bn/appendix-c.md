# পরিশিষ্ট C: ধারণা রেজিস্ট্রি

বইয়ে প্রবর্তিত প্রতিটি মূল ধারণা, তার অধ্যায়, ব্যবহৃত উপমা এবং SAA-C03 ডোমেইনে ম্যাপ করা।

পরীক্ষার আগে কোনো ধারণা অস্পষ্ট মনে হলে এটি অধ্যয়ন সূচক হিসাবে ব্যবহার করুন — এটি এখানে খুঁজুন এবং প্রসঙ্গের জন্য এর অধ্যায়ে ফিরে যান।

---

## A

**ACU (Aurora Capacity Unit)** — Aurora Serverless v2 ক্যাপাসিটির পরিমাপের একক। স্বয়ংক্রিয়ভাবে স্কেল করে। অধ্যায় ২৪। ডোমেইন ৩।

**Alarm (CloudWatch)** — এমন একটি নিয়ম যা একটি মেট্রিক একটি থ্রেশহোল্ড অতিক্রম করলে ট্রিগার হয়, একটি বিজ্ঞপ্তি বা অটো স্কেলিং অ্যাকশন ট্রিগার করে। অধ্যায় ৭। ডোমেইন ২।

**ALB (Application Load Balancer)** — Layer 7 লোড ব্যালেন্সার যা পথ এবং হোস্ট নিয়মের উপর ভিত্তি করে HTTP/HTTPS ট্র্যাফিক রুট করে। অধ্যায় ৭। ডোমেইন ২।

**AMI (Amazon Machine Image)** — EC2 ইনস্ট্যান্সের জন্য OS, সফ্টওয়্যার এবং কনফিগারেশন সহ একটি টেমপ্লেট। অধ্যায় ৪। ডোমেইন ৩।

**আর্কিটেক্ট মানসিকতা** — "কী প্রথমে ভাঙে, কীভাবে আমরা জানি, এবং রাত ৩টায় কেউ কী করে?" জিজ্ঞেস করা শুধু "এটি কীভাবে কাজ করে?" নয়। অধ্যায় ৩২, অধ্যায় ৩৪। ক্রস-ডোমেইন।

**Architecture Decision Record (ADR)** — একটি সংক্ষিপ্ত নথি যা একটি সিদ্ধান্ত, তার বিকল্প, যুক্তি এবং পুনর্বিবেচনার কারণ ক্যাপচার করে। অধ্যায় ৩২। ক্রস-ডোমেইন।

**আর্কিটেকচার পর্যালোচনা** — একটি কাঠামোগত প্রক্রিয়া কভার করে: সীমাবদ্ধতা → অজ্ঞাত → বিকল্প → ব্যর্থতার মোড → মনিটরিং → runbooks। অধ্যায় ৩২। ক্রস-ডোমেইন।

**Athena** — S3-এ ডেটার উপর সার্ভারলেস SQL কোয়েরি সার্ভিস। কোয়েরি প্রতি (স্ক্যান করা প্রতি TB) দেন। Parquet/ORC কলামার ফর্ম্যাটের সাথে সর্বোত্তম। অধ্যায় ২৬। ডোমেইন ৩।

**Auto Scaling Group (ASG)** — একসাথে পরিচালিত EC2 ইনস্ট্যান্সের একটি গ্রুপ, অটোমেটিক্যালি অস্বাস্থ্যকর ইনস্ট্যান্স প্রতিস্থাপন এবং লোডের উপর ভিত্তি করে স্কেল করে। অধ্যায় ৭। ডোমেইন ২, ৩।

**Availability Zone (AZ)** — একটি অঞ্চলের মধ্যে এক বা একাধিক ফিজিক্যালি আলাদা ডেটা সেন্টার, লো-লেটেন্সি লিঙ্ক দ্বারা সংযুক্ত। অধ্যায় ২। ডোমেইন ২।

---

## B

**Bucket (S3)** — S3 অবজেক্টের একটি কন্টেইনার। বাকেটের বৈশ্বিক অনন্য নাম থাকে এবং একটি নির্দিষ্ট অঞ্চলে থাকে। অধ্যায় ৫। ডোমেইন ৩।

**বাকেট পলিসি** — IAM principals এবং বাহ্যিক অ্যাকাউন্টের অ্যাক্সেস নিয়ন্ত্রণকারী একটি S3 বাকেটের সাথে সংযুক্ত রিসোর্স-ভিত্তিক পলিসি। অধ্যায় ৫। ডোমেইন ১।

## C

**Cache-aside প্যাটার্ন** — অ্যাপ্লিকেশন প্রথমে ক্যাশ চেক করে; মিস হলে ডেটাবেস কোয়েরি করে, তারপর ক্যাশে ফলাফল সংরক্ষণ করে। অধ্যায় ১০। ডোমেইন ৩।

**ক্যাশ হিট রেট** — অরিজিনের পরিবর্তে ক্যাশ থেকে পরিবেশিত অনুরোধের শতাংশ। বেশি ভালো। অধ্যায় ১৩। ডোমেইন ৩।

**CloudFront** — AWS CDN। বিশ্বব্যাপী ৪০০+ এজ লোকেশনে বিষয়বস্তু ক্যাশ করে। লেটেন্সি এবং অরিজিন ডেটা ট্রান্সফার খরচ কমায়। অধ্যায় ১৩। ডোমেইন ৩, ৪।

**CloudTrail** — প্রতিটি AWS API কল লগ করে: কে, কী, কখন, কোথা থেকে। S3-এ সংরক্ষিত। অডিটিং এবং ঘটনা তদন্তের জন্য ব্যবহৃত। ডোমেইন ১।

**CloudWatch** — AWS রিসোর্স এবং কাস্টম অ্যাপ্লিকেশনের মেট্রিক্স, লগ, অ্যালার্ম এবং ড্যাশবোর্ড। সর্বত্র রেফারেন্স করা। সব ডোমেইন।

**কোল্ড স্টার্ট (Lambda)** — প্রথম ইনভোকেশনে (বা নিষ্ক্রিয়তার পরে) লেটেন্সি কারণ Lambda এক্সিকিউশন এনভায়রনমেন্ট ইনিশিয়ালাইজ করে। দূর করতে Provisioned concurrency ব্যবহার করুন। অধ্যায় ২০। ডোমেইন ৩।

**Compute Savings Plan** — যেকোনো EC2 ইনস্ট্যান্সে প্রযোজ্য ঘণ্টার EC2 ব্যয়ের পরিমাণে প্রতিশ্রুতি। অধ্যায় ২৭। ডোমেইন ৪।

**Config (AWS)** — সময়ের সাথে AWS রিসোর্স কনফিগারেশন পরিবর্তন ট্র্যাক করে এবং নিয়মের বিরুদ্ধে মূল্যায়ন করে। অধ্যায় ৩১। ডোমেইন ১।

**ক্রস-AZ ডেটা ট্রান্সফার** — একই অঞ্চলে Availability Zones-এর মধ্যে ট্র্যাফিক। প্রতিটি দিকে $০.০১/GB চার্জ। অধ্যায় ৩০। ডোমেইন ৪।

**ক্রস-রিজিয়ন রেপ্লিকেশন** — ভিন্ন অঞ্চলে ডেটা (S3 CRR, Aurora Global, DynamoDB Global Tables) কপি করা। ডেটা ট্রান্সফার চার্জ বহন করে। অধ্যায় ১৮, ৩০। ডোমেইন ২।

## D

**DAX (DynamoDB Accelerator)** — DynamoDB-এর জন্য ইন-মেমরি ক্যাশ। মাইক্রোসেকেন্ড রিড লেটেন্সি। অধ্যায় ৯। ডোমেইন ৩।

**Dead Letter Queue (DLQ)** — বারবার ব্যর্থ হওয়া মেসেজ পাঠানো হয় এমন একটি কিউ, কিউ ব্লকেজ প্রতিরোধ করে। অধ্যায় ১৯। ডোমেইন ২।

**Dedicated Host** — একচেটিয়াভাবে আপনার ব্যবহারের জন্য সংরক্ষিত একটি ফিজিক্যাল EC2 সার্ভার। নির্দিষ্ট সফ্টওয়্যার লাইসেন্সের জন্য প্রয়োজনীয়। অধ্যায় ২৭। ডোমেইন ৪।

**গভীর প্রতিরক্ষা** — একাধিক নিরাপত্তা নিয়ন্ত্রণ স্তরিত করা (IAM + নিরাপত্তা গোষ্ঠী + NACL + WAF + GuardDuty) যাতে একটি স্তর ব্যর্থ হলে পরেরটি ধরে। অধ্যায় ৩৩। ডোমেইন ১।

**Direct Connect** — AWS-এর সাথে একটি অন-প্রিমিসেস অবস্থান থেকে ডেডিকেটেড প্রাইভেট নেটওয়ার্ক সংযোগ। পাবলিক ইন্টারনেট বাইপাস করে। অধ্যায় ২৫। ডোমেইন ৩।

**DLQ** — Dead Letter Queue দেখুন।

**DynamoDB** — সম্পূর্ণরূপে পরিচালিত NoSQL ডেটাবেস যেকোনো স্কেলে একক-সংখ্যা মিলিসেকেন্ড লেটেন্সি সহ। কী-ভ্যালু এবং ডকুমেন্ট মডেল। অধ্যায় ৯। ডোমেইন ৩।

**DynamoDB Auto Scaling** — CloudWatch মেট্রিক্সের উপর ভিত্তি করে স্বয়ংক্রিয়ভাবে provisioned রিড/রাইট ক্যাপাসিটি সামঞ্জস্য করে। অধ্যায় ২৯। ডোমেইন ৪।

**DynamoDB Streams** — একটি DynamoDB টেবিলে সমস্ত আইটেম পরিবর্তনের একটি সময়-অর্ডারড পরিবর্তন লগ। Lambda দিয়ে ইভেন্ট-চালিত প্রক্রিয়াকরণের জন্য ব্যবহৃত। অধ্যায় ৯। ডোমেইন ২।

## E

**EBS (Elastic Block Store)** — একটি একক EC2 ইনস্ট্যান্সের সাথে সংযুক্ত ব্লক স্টোরেজ। স্বাধীনভাবে টিকে থাকে। টাইপ: gp3, io2, st1। অধ্যায় ৬। ডোমেইন ৩।

**EC2 (Elastic Compute Cloud)** — ক্লাউডে ভার্চুয়াল মেশিন। অধ্যায় ৪। ডোমেইন ৩।

**ECS (Elastic Container Service)** — পরিচালিত কন্টেইনার অর্কেস্ট্রেশন। Fargate লঞ্চ টাইপ সার্ভার ম্যানেজমেন্ট দূর করে। অধ্যায় ২১। ডোমেইন ২, ৩।

**EFS (Elastic File System)** — একাধিক EC2 ইনস্ট্যান্স থেকে একসাথে অ্যাক্সেসযোগ্য শেয়ার্ড NFS ফাইল সিস্টেম। স্বয়ংক্রিয়ভাবে স্কেল করে। অধ্যায় ৬। ডোমেইন ৩।

**EKS (Elastic Kubernetes Service)** — AWS-এ পরিচালিত Kubernetes কন্ট্রোল প্লেন। অধ্যায় ২১। ডোমেইন ৩।

**ElastiCache** — পরিচালিত ইন-মেমরি ক্যাশিং। Redis (সমৃদ্ধ বৈশিষ্ট্য) বা Memcached (সহজ)। অধ্যায় ১০। ডোমেইন ৩।

**Elastic IP** — আপনি বরাদ্দ করতে এবং EC2 ইনস্ট্যান্সের সাথে পুনরায় সংযুক্ত করতে পারেন এমন একটি স্ট্যাটিক পাবলিক IP ঠিকানা। অধ্যায় ১১। ডোমেইন ৩।

**Envelope encryption** — ডেটা একটি data key (DEK) দিয়ে এনক্রিপ্ট হয়; DEK একটি master key (KMS-এ CMK) দিয়ে এনক্রিপ্ট হয়। অধ্যায় ১৬। ডোমেইন ১।

**EventBridge** — AWS সার্ভিস, SaaS অংশীদার এবং কাস্টম সোর্স থেকে লক্ষ্যমাত্রায় ইভেন্ট রাউট করার জন্য ইভেন্ট বাস। নির্ধারিত নিয়ম সমর্থন করে। অধ্যায় ২২। ডোমেইন ২।

**Explicit deny** — যেকোনো allow দ্বারা ওভাররাইড করা যায় না এমন একটি IAM অস্বীকার বিবৃতি। সমস্ত allow-এর উপর অগ্রাধিকার নেয়। অধ্যায় ৩। ডোমেইন ১।

## F

**Failover রাউটিং (Route 53)** — প্রাইমারি স্বাস্থ্য পরীক্ষায় ব্যর্থ হলে সেকেন্ডারি এন্ডপয়েন্টে ট্র্যাফিক রুট করে। অধ্যায় ১২। ডোমেইন ২।

**Fargate** — ECS এবং EKS-এর জন্য সার্ভারলেস কম্পিউট ইঞ্জিন। কোনো EC2 ইনস্ট্যান্স পরিচালনা করতে হয় না। অধ্যায় ২১। ডোমেইন ৩।

**Fan-out প্যাটার্ন** — একটি SNS topic একই মেসেজ একসাথে একাধিক SQS কিউতে ডেলিভারি করে। অধ্যায় ১৯। ডোমেইন ২।

**FIFO কিউ (SQS)** — ঠিক-একবার প্রক্রিয়াকরণ, কঠোর অর্ডারিং। Standard কিউগুলির তুলনায় কম থ্রুপুট। অধ্যায় ১৯। ডোমেইন ২।

**ব্যর্থতার মোড** — একটি সিস্টেম ব্যর্থ হতে পারে এমন একটি নির্দিষ্ট উপায়। প্রোডাকশনের আগে ব্যর্থতার মোড চিহ্নিত করা আর্কিটেকচার পর্যালোচনার মূল বিষয়। অধ্যায় ৩২। ক্রস-ডোমেইন।

## G

**Gateway Endpoint** — S3 এবং DynamoDB-এর জন্য একটি বিনামূল্যে VPC endpoint টাইপ। AWS প্রাইভেট নেটওয়ার্কের মাধ্যমে ট্র্যাফিক রুট করে, NAT Gateway চার্জ দূর করে। অধ্যায় ৩০। ডোমেইন ৪।

**Geolocation রাউটিং (Route 53)** — DNS কোয়েরি উৎসের ভৌগোলিক অবস্থানের উপর ভিত্তি করে রুট করে। অধ্যায় ১২। ডোমেইন ৩।

**Global Accelerator** — Anycast ব্যবহার করে নিকটতম AWS এজে ট্র্যাফিক রুট করে, গতিশীল অ্যাপ্লিকেশনের লেটেন্সি উন্নত করে। অধ্যায় ২৫। ডোমেইন ৩।

**Glue (AWS)** — সার্ভারলেস ETL। Glue Crawlers স্কিমা আবিষ্কার করে; Glue Jobs ডেটা রূপান্তর করে; Data Catalog মেটাডেটা সংরক্ষণ করে। অধ্যায় ২৬। ডোমেইন ৩।

**GSI (Global Secondary Index)** — একটি ভিন্ন পার্টিশন কী এবং ঐচ্ছিক সর্ট কী সহ একটি DynamoDB টেবিলে একটি বিকল্প সূচক। ফ্লেক্সিবল কোয়েরি প্যাটার্ন সক্ষম করে। অধ্যায় ৯। ডোমেইন ৩।

**GuardDuty** — CloudTrail, VPC Flow Logs এবং DNS লগের উপর ML ব্যবহার করে অস্বাভাবিক কার্যকলাপ সনাক্ত করার হুমকি সনাক্তকরণ সার্ভিস। অধ্যায় ১৭। ডোমেইন ১।

## H

**স্বাস্থ্য পরীক্ষা (Route 53)** — এন্ডপয়েন্টের প্রাপ্যতা মনিটর করে। ব্যর্থ স্বাস্থ্য পরীক্ষা failover রাউটিং ট্রিগার করে। অধ্যায় ১২। ডোমেইন ২।

**হট পার্টিশন (DynamoDB)** — একটি পার্টিশন যা অসামঞ্জস্যপূর্ণ ট্র্যাফিক পায় কারণ অনেক অনুরোধ একই পার্টিশন কী ভাগ করে। অধ্যায় ৯। ডোমেইন ৩।

## I

**IAM (Identity and Access Management)** — AWS অ্যাকাউন্টের জন্য প্রমাণীকরণ এবং অনুমোদন নিয়ন্ত্রণ করে। ব্যবহারকারী, গ্রুপ, রোল, পলিসি। অধ্যায় ৩, ১৪। ডোমেইন ১।

**IAM রোল** — সার্ভিস, ব্যবহারকারী বা অন্য অ্যাকাউন্ট দ্বারা গ্রহণযোগ্য অস্থায়ী ক্রেডেনশিয়াল সহ একটি IAM পরিচয়। অধ্যায় ৩, ১৪। ডোমেইন ১।

**Idempotency** — এমন একটি অপারেশনের বৈশিষ্ট্য যা একবার বা অনেকবার কল করা হলে একই ফলাফল তৈরি করে। বিতরণ করা সিস্টেমের জন্য সমালোচনামূলক (রিফান্ড, পেমেন্ট, অর্ডার প্রক্রিয়াকরণ)। অধ্যায় ৩২। ক্রস-ডোমেইন।

**Idempotency key** — একটি অপারেশনের জন্য একটি অনন্য identifier, ডুপ্লিকেট প্রক্রিয়াকরণ প্রতিরোধ করতে এক্সিকিউশনের আগে চেক করা হয়। অধ্যায় ৩২। ক্রস-ডোমেইন।

**Interface Endpoint (PrivateLink)** — বেশিরভাগ AWS সার্ভিসের জন্য একটি VPC endpoint। ঘণ্টা + প্রতি GB মূল্য নির্ধারিত। ইন্টারনেট বা NAT ছাড়াই প্রাইভেট সংযোগ প্রদান করে। অধ্যায় ৩০। ডোমেইন ৪।

**Internet Gateway (IGW)** — পাবলিক সাবনেটে ইনস্ট্যান্সগুলিকে ইন্টারনেটের সাথে যোগাযোগ করতে দেয়। সাবনেটের রুট টেবিলের IGW-তে একটি রুট থাকতে হবে। অধ্যায় ১১। ডোমেইন ৩।

**"নির্ভর করে"** — প্রায় প্রতিটি আর্কিটেকচার প্রশ্নের সৎ উত্তর, যা সবসময় সম্পূর্ণ করতে হবে: "অ্যাক্সেস প্যাটার্ন / স্কেল / ব্যর্থতার পরিণতি / খরচের সীমাবদ্ধতার উপর নির্ভর করে।" অধ্যায় ৩৩। ক্রস-ডোমেইন।

## K

**Kinesis Data Firehose** — S3, Redshift, OpenSearch-এ স্ট্রিমিং ডেটার পরিচালিত ডেলিভারি। কোনো গ্রাহক ম্যানেজমেন্ট নেই। অধ্যায় ২৬। ডোমেইন ৩।

**Kinesis Data Streams** — রিয়েল-টাইম অর্ডারড ইভেন্ট স্ট্রিম। টেকসই, রিপ্লেযোগ্য। shards-এ মাপা। অধ্যায় ২৬। ডোমেইন ৩।

**KMS (Key Management Service)** — বিশ্রামে এনক্রিপশনের জন্য ক্রিপ্টোগ্রাফিক কী তৈরি, সংরক্ষণ এবং নিয়ন্ত্রণ করে। অধ্যায় ১৬। ডোমেইন ১।

## L

**Lambda** — ইভেন্ট দ্বারা ট্রিগার করা সার্ভারলেস ফাংশন। প্রতি ইনভোকেশন এবং প্রতি ms দেন। সর্বোচ্চ ১৫-মিনিটের সময়কাল। অধ্যায় ২০। ডোমেইন ২, ৩, ৪।

**Lambda@Edge** — CloudFront এজ লোকেশনে চলে Lambda ফাংশন, অনুরোধ এবং প্রতিক্রিয়া পরিবর্তন করে। অধ্যায় ১৩। ডোমেইন ৩।

**Latency-based রাউটিং (Route 53)** — সর্বনিম্ন পরিমাপকৃত লেটেন্সি সহ AWS অঞ্চলে DNS কোয়েরি রুট করে। অধ্যায় ১২। ডোমেইন ৩।

**লঞ্চ টেমপ্লেট** — Auto Scaling Groups-এর জন্য EC2 ইনস্ট্যান্স কনফিগারেশন নির্দিষ্ট করে একটি সংস্করণযুক্ত টেমপ্লেট। অধ্যায় ৭। ডোমেইন ৩।

**ন্যূনতম সুবিধা** — IAM সর্বোত্তম অনুশীলন: শুধুমাত্র প্রয়োজনীয় অনুমতি প্রদান করুন, আর নয়। অধ্যায় ৩। ডোমেইন ১।

**লাইফসাইকেল পলিসি (S3)** — নিয়ম যা বয়সের উপর ভিত্তি করে স্টোরেজ ক্লাসের মধ্যে স্বয়ংক্রিয়ভাবে অবজেক্ট ট্রানজিট করে বা মুছে দেয়। অধ্যায় ২৩। ডোমেইন ৪।

**LSI (Local Secondary Index)** — একই পার্টিশন কী কিন্তু ভিন্ন সর্ট কী সহ একটি DynamoDB টেবিলে একটি বিকল্প সূচক। টেবিল তৈরিতে তৈরি করতে হবে। অধ্যায় ৯। ডোমেইন ৩।

## M

**Memcached** — সহজ, মাল্টি-থ্রেডেড ইন-মেমরি ক্যাশিং ইঞ্জিন। কোনো স্থায়িত্ব নেই, কোনো ডেটা স্ট্রাকচার নেই। বৈশিষ্ট্যের খরচে মাল্টি-থ্রেডিং-এর বিশেষভাবে প্রয়োজন না হলে Redis ব্যবহার করুন। অধ্যায় ১০। ডোমেইন ৩।

**Multi-AZ (RDS)** — স্বয়ংক্রিয় ফেলওভার সহ একটি ভিন্ন AZ-এ সিঙ্ক্রোনাস স্ট্যান্ডবাই রেপ্লিকা। RPO ~০, RTO ~৬০ সেকেন্ড। উচ্চ প্রাপ্যতার জন্য, রিড স্কেলিং নয়। অধ্যায় ৮, ১৮। ডোমেইন ২।

**Multi-Region** — ভৌগোলিক রিডান্ডেন্সি এবং গ্লোবাল পারফরম্যান্সের জন্য একাধিক AWS অঞ্চলে অ্যাপ্লিকেশন উপাদান ডিপ্লয় করা। উচ্চতর জটিলতা এবং খরচ। অধ্যায় ১৮। ডোমেইন ২।

---

## N

**NACL (Network Access Control List)** — সাবনেট স্তরে স্টেটলেস ফায়ারওয়াল। ইনবাউন্ড এবং আউটবাউন্ড উভয় নিয়ম প্রয়োজন। নিয়ম নম্বর অনুসারে মূল্যায়ন করা হয়। অধ্যায় ১৫। ডোমেইন ১।

**NAT Gateway** — প্রাইভেট সাবনেটে ইনস্ট্যান্সগুলিকে ইন্টারনেটে আউটবাউন্ড সংযোগ করতে দেয়। প্রক্রিয়া করা প্রতি GB-তে $০.০৪৫ চার্জ। অধ্যায় ১১, ৩০। ডোমেইন ৪।

---

## O

**Object (S3)** — S3-এ সংরক্ষিত একটি ফাইল। key (নাম), value (ডেটা) এবং মেটাডেটা নিয়ে গঠিত। সর্বোচ্চ আকার ৫TB। অধ্যায় ৫। ডোমেইন ৩।

**On-Demand ক্যাপাসিটি (DynamoDB)** — প্রতি-অনুরোধে পে মোড। প্রতি অনুরোধে provisioned-এর চেয়ে বেশি ব্যয়বহুল, কিন্তু কোনো ক্যাপাসিটি পরিকল্পনার প্রয়োজন নেই। অধ্যায় ২৯। ডোমেইন ৪।

**On-Demand ইনস্ট্যান্স (EC2)** — কোনো প্রতিশ্রুতি ছাড়াই ঘণ্টা-হিসাবে পে। সর্বোচ্চ নমনীয়তা, সর্বোচ্চ মূল্য। অধ্যায় ২৭। ডোমেইন ৪।

---

## P

**Partition key (DynamoDB)** — প্রাইমারি কী উপাদান যা নির্ধারণ করে কোন পার্টিশনে একটি আইটেম সংরক্ষিত হয়। সমান বিতরণের জন্য একটি উচ্চ-কার্ডিনালিটি কী বেছে নিন। অধ্যায় ৯। ডোমেইন ৩।

**Permission boundary** — একটি IAM পলিসি যা সর্বোচ্চ অনুমতি সেট করে একটি IAM পরিচয় থাকতে পারে, এমনকি যদি অন্য পলিসি আরো দেয়। অধ্যায় ১৪। ডোমেইন ১।

**Placement group** — লেটেন্সি কমাতে (cluster) বা প্রাপ্যতা সর্বাধিক করতে (spread) EC2 ইনস্ট্যান্সের ফিজিক্যাল স্থাপন নিয়ন্ত্রণ করে। অধ্যায় ৪। ডোমেইন ৩।

**PrivateLink** — AWS সার্ভিসে এবং AWS গ্রাহকদের দ্বারা হোস্ট করা সার্ভিসে প্রাইভেট এন্ডপয়েন্ট তৈরির জন্য AWS সার্ভিস, Interface Endpoints-এর মাধ্যমে অ্যাক্সেসযোগ্য। অধ্যায় ৩০। ডোমেইন ১।

**Provisioned concurrency (Lambda)** — প্রি-ইনিশিয়ালাইজড এক্সিকিউশন এনভায়রনমেন্ট যা কোল্ড স্টার্ট বিলম্ব দূর করে। অধ্যায় ২০। ডোমেইন ৩।

**Provisioned ক্যাপাসিটি (DynamoDB)** — প্রি-অ্যালোকেটেড রিড এবং রাইট থ্রুপুট, প্রতি সেকেন্ডে ক্যাপাসিটি ইউনিটে মাপা। পূর্বাভাসযোগ্য ট্র্যাফিকের জন্য on-demand-এর চেয়ে সস্তা। অধ্যায় ৯, ২৯। ডোমেইন ৪।

---

## R

**RDS (Relational Database Service)** — পরিচালিত রিলেশনাল ডেটাবেস। ব্যাকআপ, প্যাচিং, ফেলওভার পরিচালনা করে। অধ্যায় ৮। ডোমেইন ৩।

**RDS Proxy** — Lambda/অ্যাপ্লিকেশন এবং RDS-এর মধ্যে একটি কানেকশন পুল পরিচালনা করে, কানেকশন এক্সহস্ট প্রতিরোধ করে। অধ্যায় ৮। ডোমেইন ৩।

**Read Replica (RDS)** — রিড স্কেলিংয়ের জন্য ডেটাবেসের অ্যাসিঙ্ক্রোনাস কপি। স্বয়ংক্রিয় ফেলওভার প্রদান করে না। অধ্যায় ৮, ২৪। ডোমেইন ৩।

**Redis** — ক্যাশিং, সেশন ম্যানেজমেন্ট, রিয়েল-টাইম লিডারবোর্ড, pub/sub-এর জন্য ইন-মেমরি ডেটা স্ট্রাকচার স্টোর। অধ্যায় ১০। ডোমেইন ৩।

**Reserved Instance (EC2)** — একটি নির্দিষ্ট অঞ্চলে একটি নির্দিষ্ট ইনস্ট্যান্স টাইপ ১ বা ৩ বছরের জন্য ব্যবহার করার প্রতিশ্রুতি ছাড়ের বিনিময়ে। অধ্যায় ২৭। ডোমেইন ৪।

**Route 53** — AWS DNS সার্ভিস এবং ডোমেইন রেজিস্ট্রার। একাধিক রাউটিং পলিসি সমর্থন করে। অধ্যায় ১২। ডোমেইন ২, ৩।

**RPO (Recovery Point Objective)** — সময়ে পরিমাপকৃত সর্বোচ্চ গ্রহণযোগ্য ডেটা ক্ষতি। "আমরা কত ডেটা হারাতে পারি?" অধ্যায় ১৮। ডোমেইন ২।

**RTO (Recovery Time Objective)** — একটি ব্যর্থতার পরে সার্ভিস পুনরুদ্ধার করার সর্বোচ্চ গ্রহণযোগ্য সময়। "আমরা কতক্ষণ ডাউন থাকতে পারি?" অধ্যায় ১৮। ডোমেইন ২।

**Runbook** — একটি সিস্টেম পরিচালনার জন্য ধাপে ধাপে নির্দেশাবলী, বিশেষত ঘটনা প্রতিক্রিয়ার জন্য। "রাত ৩টায় কেউ কী করে?" অধ্যায় ৩২। ক্রস-ডোমেইন।

---

## S

**S3 Intelligent-Tiering** — অ্যাক্সেস প্যাটার্নের উপর ভিত্তি করে স্বয়ংক্রিয়ভাবে অ্যাক্সেস টায়ারের মধ্যে S3 অবজেক্ট সরায়। কোনো পুনরুদ্ধার ফি নেই। অধ্যায় ২৩। ডোমেইন ৪।

**S3 Select** — SQL এক্সপ্রেশন ব্যবহার করে একটি S3 অবজেক্টের বিষয়বস্তুর একটি উপসেট পুনরুদ্ধার করে, ডেটা ট্রান্সফার কমিয়ে। অধ্যায় ৩০। ডোমেইন ৪।

**Savings Plan** — প্রতিশ্রুতির বিনিময়ে ছাড়ের জন্য একটি নমনীয় মূল্য নির্ধারণ মডেল ঘণ্টার ব্যয়ের পরিমাণে। Reserved Instances-এর চেয়ে আরো নমনীয়। অধ্যায় ২৭। ডোমেইন ৪।

**SCP (Service Control Policy)** — AWS Organizations পলিসি যা একটি OU-তে অ্যাকাউন্টের জন্য উপলব্ধ সর্বোচ্চ অনুমতি সীমিত করে। অধ্যায় ১৪। ডোমেইন ১।

**Secrets Manager** — secrets (ডেটাবেস পাসওয়ার্ড, API কী) সংরক্ষণ করে এবং স্বয়ংক্রিয়ভাবে রোটেট করে। অধ্যায় ১৬। ডোমেইন ১।

**নিরাপত্তা গোষ্ঠী** — ইনস্ট্যান্স স্তরে স্টেটফুল ভার্চুয়াল ফায়ারওয়াল। শুধুমাত্র অনুমতির নিয়ম; রিটার্ন ট্র্যাফিক স্বয়ংক্রিয়। অধ্যায় ১৫। ডোমেইন ১।

**Shard (Kinesis)** — Kinesis Data Streams-এ থ্রুপুটের বেস ইউনিট: ১ MB/s রাইট, ২ MB/s রিড। অধ্যায় ২৬। ডোমেইন ৩।

**Shared Responsibility Model** — AWS ক্লাউডের নিরাপত্তার জন্য দায়িত্বশীল (অবকাঠামো); আপনি ক্লাউডে নিরাপত্তার জন্য দায়িত্বশীল (ডেটা, কনফিগারেশন, অ্যাক্সেস)। অধ্যায় ১। ডোমেইন ১।

**Shield** — DDoS সুরক্ষা। Standard: বিনামূল্যে, স্বয়ংক্রিয়। Advanced: প্রদত্ত, DRT সমর্থন এবং আর্থিক সুরক্ষা সহ। অধ্যায় ১৭। ডোমেইন ১।

**SNS (Simple Notification Service)** — Pub/sub মেসেজিং। একসাথে সমস্ত subscriber-এ মেসেজ পুশ করে। Fan-out প্যাটার্ন। অধ্যায় ১৯। ডোমেইন ২।

**Sort key (DynamoDB)** — প্রাইমারি কীর ঐচ্ছিক দ্বিতীয় উপাদান। একটি পার্টিশনের মধ্যে range কোয়েরি সক্ষম করে। অধ্যায় ৯। ডোমেইন ৩।

**Spot Instances** — ৬০-৯০% ছাড়ে স্পেয়ার EC2 ক্যাপাসিটি ব্যবহার করে। ২-মিনিটের নোটিশে বাধা হতে পারে। শুধুমাত্র ফল্ট-টলেরেন্ট ওয়ার্কলোডের জন্য। অধ্যায় ২৭। ডোমেইন ৪।

**SQS (Simple Queue Service)** — পরিচালিত মেসেজ কিউ। প্রযোজক থেকে গ্রাহক ডিকাপল করে। Standard (অন্তত-একবার) এবং FIFO (ঠিক-একবার) কিউ। অধ্যায় ১৯। ডোমেইন ২।

**Step Functions** — সার্ভারলেস ওয়ার্কফ্লো অর্কেস্ট্রেশন সার্ভিস। AWS সার্ভিস সমন্বয় করার জন্য স্টেট মেশিন। অধ্যায় ২২। ডোমেইন ২।

---

## T

**Target tracking স্কেলিং** — একটি টার্গেট মেট্রিক মান বজায় রাখতে ক্যাপাসিটি সামঞ্জস্য করে এমন Auto Scaling পলিসি (যেমন ৬০% CPU ব্যবহার)। অধ্যায় ৭। ডোমেইন ২।

**Transit Gateway** — একটি কেন্দ্রীয় গেটওয়ের মাধ্যমে একাধিক VPC এবং অন-প্রিমিসেস নেটওয়ার্ক সংযুক্ত করে হাব-এন্ড-স্পোক নেটওয়ার্ক টপোলজি। অধ্যায় ২৫। ডোমেইন ৩।

**TTL (Time to Live)** — একটি টাইমস্ট্যাম্প যার পরে DynamoDB স্বয়ংক্রিয়ভাবে একটি আইটেম মুছে দেয়। DNS-এও ব্যবহৃত (resolvers কত সময় একটি রেকর্ড ক্যাশ করে) এবং ক্যাশিং (একটি ক্যাশড মান কতক্ষণ বৈধ)। অধ্যায় ৯, ১২। ডোমেইন ৩।

---

## V

**VIF (Virtual Interface)** — AWS Direct Connect-এর সাথে ব্যবহৃত লজিক্যাল সংযোগ। Public VIF AWS পাবলিক এন্ডপয়েন্ট অ্যাক্সেস করে; Private VIF VPC রিসোর্স অ্যাক্সেস করে। অধ্যায় ২৫। ডোমেইন ৩।

**Visibility timeout (SQS)** — সেই সময়কাল যার মধ্যে একটি প্রাপ্ত মেসেজ অন্য গ্রাহকদের থেকে লুকানো থাকে। প্রক্রিয়াকরণের সময় অন্য গ্রাহকরা একই মেসেজ দেখতে পায় না। অধ্যায় ১৯। ডোমেইন ২।

**VPC (Virtual Private Cloud)** — AWS-এ একটি বিচ্ছিন্ন ভার্চুয়াল নেটওয়ার্ক। সাবনেট, রুট টেবিল এবং গেটওয়ে ধারণ করে। অধ্যায় ১১। ডোমেইন ১।

**VPC Endpoint** — AWS প্রাইভেট নেটওয়ার্কের মাধ্যমে AWS সার্ভিসে VPC রিসোর্স সংযুক্ত করে। Gateway (বিনামূল্যে, S3/DynamoDB) এবং Interface (মূল্য নির্ধারিত, বেশিরভাগ অন্যান্য সার্ভিস)। অধ্যায় ৩০। ডোমেইন ১, ৪।

**VPC Flow Logs** — VPC-তে নেটওয়ার্ক ইন্টারফেসে এবং থেকে IP ট্র্যাফিক সম্পর্কে তথ্য ক্যাপচার করে। GuardDuty দ্বারা ব্যবহৃত এবং নেটওয়ার্ক ট্রাবলশুটিংয়ের জন্য। অধ্যায় ১৭। ডোমেইন ১।

**VPC Peering** — প্রাইভেট IP ঠিকানা ব্যবহার করে তাদের মধ্যে ট্র্যাফিক রাউট করতে দুটি VPC-এর মধ্যে নেটওয়ার্ক সংযোগ। অধ্যায় ১১। ডোমেইন ৩।

---

## W

**WAF (Web Application Firewall)** — নিয়মের উপর ভিত্তি করে HTTP/HTTPS ট্র্যাফিক ফিল্টার করে (IP ব্লক, SQL injection, রেট সীমা)। CloudFront, ALB, বা API Gateway-এ সংযুক্ত করে। অধ্যায় ১৭। ডোমেইন ১।

**Well-Architected Framework** — AWS-এর ছয়-স্তম্ভ মূল্যায়ন ফ্রেমওয়ার্ক: অপারেশনাল এক্সেলেন্স, নিরাপত্তা, নির্ভরযোগ্যতা, পারফরম্যান্স দক্ষতা, খরচ অপ্টিমাইজেশন, স্থায়িত্ব। অধ্যায় ৩১। ক্রস-ডোমেইন।

**Weighted রাউটিং (Route 53)** — ওজন দ্বারা এন্ডপয়েন্ট জুড়ে DNS কোয়েরি বিতরণ করে। blue-green ডিপ্লয়মেন্ট এবং A/B পরীক্ষার জন্য ব্যবহৃত। অধ্যায় ১২। ডোমেইন ৩।

**Write-through ক্যাশিং** — ডেটাবেস আপডেট হলে ক্যাশ আপডেট করে। ডেটা সবসময় সামঞ্জস্যপূর্ণ কিন্তু ক্যাশে অনেক আইটেম থাকতে পারে যা কখনো পুনরায় পড়া হয় না। অধ্যায় ১০। ডোমেইন ৩।

# পরিশিষ্ট C: ধারণা রেজিস্ট্রি

বইয়ে প্রবর্তিত প্রতিটি মূল ধারণা, এর অধ্যায়, ব্যবহৃত উপমা এবং এটি যে SAA-C03 ডোমেইনে প্রদর্শিত হয় সেখানে ম্যাপ করা হয়েছে।

এটি একটি অধ্যয়ন সূচী হিসাবে ব্যবহার করুন: পরীক্ষার আগে আপনি যদি একটি ধারণা সম্পর্কে অস্পষ্ট থাকেন, এখানে এটি খুঁজুন এবং প্রসঙ্গের জন্য এর অধ্যায়ে ফিরে যান।

---

## A

**ACM (AWS Certificate Manager)** — ALB, CloudFront এবং API Gateway-এর জন্য বিনামূল্যে পাবলিক TLS সার্টিফিকেট, DNS যাচাইকরণের মাধ্যমে স্বয়ংক্রিয় নবায়ন সহ। CloudFront সার্টিফিকেট অবশ্যই us-east-1-এ থাকতে হবে। অধ্যায় 16। ডোমেইন 1।

**ACU (Aurora Capacity Unit)** — Aurora Serverless v2 ক্যাপাসিটির পরিমাপের একক। স্বয়ংক্রিয়ভাবে স্কেল করে এবং, সমর্থিত ইঞ্জিন সংস্করণে, কোনো কানেকশন খোলা না থাকলে 0 ACUs-এ auto-pause করতে পারে। অধ্যায় 24। ডোমেইন 3।

**Alarm (CloudWatch)** — একটি নিয়ম যা একটি মেট্রিক একটি থ্রেশহোল্ড অতিক্রম করলে ট্রিগার হয়, একটি নোটিফিকেশন বা অটো স্কেলিং অ্যাকশন ট্রিগার করে। অধ্যায় 7। ডোমেইন 2।

**ALB (Application Load Balancer)** — Layer 7 লোড ব্যালেন্সার যা পথ এবং হোস্ট নিয়মের উপর ভিত্তি করে HTTP/HTTPS ট্র্যাফিক রুট করে। অধ্যায় 7। ডোমেইন 2।

**AMI (Amazon Machine Image)** — একটি EC2 ইনস্ট্যান্সের জন্য OS, সফটওয়্যার এবং কনফিগারেশন ধারণকারী একটি টেমপ্লেট। অধ্যায় 4। ডোমেইন 3।

**আর্কিটেক্ট মাইন্ডসেট** — কেবল "এটি কীভাবে কাজ করে?" নয় বরং "প্রথমে কী ভাঙে, আমরা কীভাবে জানি, এবং রাত 3টায় কেউ কী করে?" জিজ্ঞাসা করা। অধ্যায় 32, অধ্যায় 34। ক্রস-ডোমেইন।

**Architecture Decision Record (ADR)** — একটি সংক্ষিপ্ত নথি যা একটি সিদ্ধান্ত, এর বিকল্প, এর যুক্তি এবং কী পুনর্বিবেচনার কারণ হবে তা ধারণ করে। অধ্যায় 32। ক্রস-ডোমেইন।

**আর্কিটেকচার পর্যালোচনা** — একটি কাঠামোগত প্রক্রিয়া যা কভার করে: সীমাবদ্ধতা → অজানা → বিকল্প → ব্যর্থতা মোড → মনিটরিং → রানবুক। অধ্যায় 32। ক্রস-ডোমেইন।

**Athena** — S3-তে ডেটার জন্য সার্ভারলেস SQL কোয়েরি সার্ভিস। প্রতি TB স্ক্যান করায় দেন। Parquet/ORC কলামার ফরম্যাটের সাথে সেরা। অধ্যায় 26। ডোমেইন 3।

**Auto Scaling Group (ASG)** — একসাথে পরিচালিত EC2 ইনস্ট্যান্সের একটি গ্রুপ, স্বয়ংক্রিয়ভাবে অস্বাস্থ্যকর ইনস্ট্যান্স প্রতিস্থাপন করে এবং লোডের উপর ভিত্তি করে স্কেল করে। অধ্যায় 7। ডোমেইন 2, 3।

**Availability Zone (AZ)** — একটি অঞ্চলের মধ্যে এক বা একাধিক শারীরিকভাবে পৃথক ডেটা সেন্টার, লো-লেটেন্সি লিঙ্ক দ্বারা সংযুক্ত। অধ্যায় 2। ডোমেইন 2।

---

## B

**AWS Backup** — EBS, RDS, DynamoDB, EFS এবং Storage Gateway জুড়ে কেন্দ্রীভূত, পলিসি-ভিত্তিক ব্যাকআপ। ক্রস-রিজিয়ন এবং ক্রস-অ্যাকাউন্ট কপি সমর্থন করে। অধ্যায় 18, 23। ডোমেইন 2।

**AWS Batch** — Docker কন্টেইনারের জন্য পরিচালিত ব্যাচ কম্পিউট। একটি জব ডেফিনিশন (কী চালাতে হবে), একটি জব কিউ (যেখানে জব অপেক্ষা করে) এবং একটি কম্পিউট এনভায়রনমেন্ট (EC2 বা Fargate, On-Demand বা Spot) দ্বারা গঠিত। Lambda-র 15-মিনিট সীমা অতিক্রমকারী ওয়ার্কলোডের জন্য। অধ্যায় 21। ডোমেইন 3।

**Bucket (S3)** — S3 অবজেক্টের জন্য একটি কন্টেইনার। বাকেটের অনন্য গ্লোবাল নাম থাকে এবং একটি নির্দিষ্ট অঞ্চলে থাকে। অধ্যায় 5। ডোমেইন 3।

**Bucket policy** — একটি S3 বাকেটের সাথে সংযুক্ত একটি resource-based পলিসি যা IAM principal এবং বহিরাগত অ্যাকাউন্টের অ্যাক্সেস নিয়ন্ত্রণ করে। অধ্যায় 5। ডোমেইন 1।

## C

**Cache-aside প্যাটার্ন** — অ্যাপ্লিকেশন প্রথমে ক্যাশ পরীক্ষা করে; মিসে, ডেটাবেস কোয়েরি করে, তারপর ফলাফল ক্যাশে সংরক্ষণ করে। অধ্যায় 10। ডোমেইন 3।

**Cache hit rate** — অরিজিনের পরিবর্তে ক্যাশ থেকে পরিবেশিত অনুরোধের শতাংশ। বেশি ভালো। অধ্যায় 13। ডোমেইন 3।

**AWS Client VPN** — পরিচালিত OpenVPN এন্ডপয়েন্ট। ইন্টারনেটের মাধ্যমে পৃথক ডিভাইসকে (ল্যাপটপ, ওয়ার্কস্টেশন) একটি VPC-তে সংযুক্ত করে। Active Directory, একটি আইডেন্টিটি প্রদানকারীর সাথে SAML 2.0 ফেডারেশন, বা mutual TLS-এর মাধ্যমে প্রমাণীকরণ। split-tunnel এবং full-tunnel মোড সমর্থন করে। Site-to-Site VPN (নেটওয়ার্ক-টু-নেটওয়ার্ক) এর সাথে তুলনা করুন। অধ্যায় 11। ডোমেইন 1।

**CloudFront** — AWS CDN। বিশ্বব্যাপী 750+ এজ লোকেশনে কন্টেন্ট ক্যাশ করে। লেটেন্সি এবং অরিজিন ডেটা ট্রান্সফার খরচ কমায়। অধ্যায় 13। ডোমেইন 3, 4।

**CloudTrail** — প্রতিটি AWS API কল লগ করে: কে, কী, কখন, কোথা থেকে। S3-তে সংরক্ষিত। অডিটিং এবং ঘটনা তদন্তের জন্য ব্যবহৃত। ডোমেইন 1।

**CloudWatch** — AWS রিসোর্স এবং কাস্টম অ্যাপ্লিকেশনের জন্য মেট্রিক, লগ, অ্যালার্ম এবং ড্যাশবোর্ড। সর্বত্র উল্লেখিত। সব ডোমেইন।

**Amazon Cognito** — আপনার অ্যাপ্লিকেশনের শেষ ব্যবহারকারীদের জন্য প্রমাণীকরণ: User Pools একটি পরিচালিত ব্যবহারকারী ডিরেক্টরি (সাইন-আপ, সাইন-ইন, MFA, সোশ্যাল লগইন, JWTs); Identity Pools অস্থায়ী AWS ক্রেডেনশিয়াল ইস্যু করে। IAM আপনার ইঞ্জিনিয়ারদের জন্য; Cognito আপনার গ্রাহকদের জন্য। অধ্যায় 14। ডোমেইন 1।

**Cold start (Lambda)** — প্রথম ইনভোকেশনে (বা নিষ্ক্রিয়তার পরে) বিলম্ব যখন Lambda এক্সিকিউশন এনভায়রনমেন্ট ইনিশিয়ালাইজ করে। দূর করতে provisioned concurrency ব্যবহার করুন। অধ্যায় 20। ডোমেইন 3।

**Compute Savings Plan** — ঘণ্টায় EC2 ব্যয়ের একটি ডলার পরিমাণের প্রতিশ্রুতি, যেকোনো ইনস্ট্যান্স টাইপ বা সাইজে প্রযোজ্য। অধ্যায় 27। ডোমেইন 4।

**Config (AWS)** — সময়ের সাথে AWS রিসোর্সের কনফিগারেশন পরিবর্তন ট্র্যাক করে এবং নিয়মের বিপরীতে কমপ্লায়েন্স মূল্যায়ন করে। অধ্যায় 31। ডোমেইন 1।

**AWS Control Tower** — মাল্টি-অ্যাকাউন্ট গভর্নেন্স স্বয়ংক্রিয় করে: গার্ডরেল সহ একটি landing zone (ম্যানেজমেন্ট, লগ আর্কাইভ এবং অডিট অ্যাকাউন্ট) মিনিটে তৈরি করে — হাতে Organizations, CloudTrail এবং Config ওয়্যার করার প্রিফ্যাব সংস্করণ। অধ্যায় 14। ডোমেইন 1।

**Cross-AZ ডেটা ট্রান্সফার** — একটি অঞ্চলের মধ্যে Availability Zones-এর মধ্যে ট্র্যাফিক। প্রতি দিকে $0.01/GB চার্জ করা হয়। অধ্যায় 30। ডোমেইন 4।

**Cross-region রেপ্লিকেশন** — একটি ভিন্ন অঞ্চলে ডেটা (S3 CRR, Aurora Global, DynamoDB Global Tables) কপি করা। ডেটা ট্রান্সফার চার্জ লাগে। অধ্যায় 18, 23, 30। ডোমেইন 2।

## D

**AWS DataSync** — ফাইল শেয়ার (NFS/SMB) এর S3, EFS, বা FSx-এ এজেন্ট-ভিত্তিক মাইগ্রেশন এবং সিঙ্ক। "rsync স্টেরয়েডে, একটি AWS কনসোল সহ।" অধ্যায় 25। ডোমেইন 3।

**DAX (DynamoDB Accelerator)** — বিশেষভাবে DynamoDB-এর জন্য ইন-মেমরি ক্যাশ। মাইক্রোসেকেন্ড রিড লেটেন্সি। অধ্যায় 9। ডোমেইন 3।

**Dead Letter Queue (DLQ)** — একটি কিউ যেখানে বারবার প্রসেসিং ব্যর্থ হওয়া মেসেজ পাঠানো হয়, কিউ ব্লকেজ প্রতিরোধ করে। অধ্যায় 19। ডোমেইন 2।

**AWS DMS (Database Migration Service)** — ন্যূনতম ডাউনটাইম সহ ডেটাবেস AWS-এ মাইগ্রেট করে। Full load (প্রাথমিক কপি) এবং CDC (Change Data Capture) মাইগ্রেশন চলাকালীন সোর্স এবং টার্গেটকে সিঙ্কে রাখে। Homogeneous মাইগ্রেশন (একই ইঞ্জিন টাইপ): সরাসরি DMS ব্যবহার করুন। Heterogeneous মাইগ্রেশন (ভিন্ন ইঞ্জিন টাইপ, যেমন Oracle → Aurora PostgreSQL): প্রথমে SCT (Schema Conversion Tool), তারপর DMS। অধ্যায় 8। ডোমেইন 3।

**Dedicated Host** — আপনার একচেটিয়া ব্যবহারের জন্য সংরক্ষিত একটি শারীরিক EC2 সার্ভার। নির্দিষ্ট সফটওয়্যার লাইসেন্সের জন্য প্রয়োজন। অধ্যায় 27। ডোমেইন 4।

**Defense in depth** — একাধিক নিরাপত্তা নিয়ন্ত্রণ স্তরে স্থাপন (IAM + নিরাপত্তা গোষ্ঠী + NACL + WAF + GuardDuty) যাতে একটি স্তরের আপস সিস্টেমকে উন্মুক্ত না করে। অধ্যায় 33। ডোমেইন 1।

**Direct Connect** — একটি অন-প্রিমিসেস অবস্থান থেকে AWS-এ একটি ডেডিকেটেড প্রাইভেট নেটওয়ার্ক সংযোগ। VPN-এর চেয়ে আরও সামঞ্জস্যপূর্ণ। অধ্যায় 25। ডোমেইন 3।

**DLQ** — Dead Letter Queue দেখুন।

**DynamoDB** — সম্পূর্ণরূপে পরিচালিত NoSQL ডেটাবেস, যেকোনো স্কেলে একক-সংখ্যা মিলিসেকেন্ড লেটেন্সি সহ। কী-ভ্যালু এবং ডকুমেন্ট মডেল। অধ্যায় 9। ডোমেইন 3।

**DynamoDB Auto Scaling** — CloudWatch মেট্রিকের উপর ভিত্তি করে স্বয়ংক্রিয়ভাবে provisioned read/write ক্যাপাসিটি সামঞ্জস্য করে। অধ্যায় 29। ডোমেইন 4।

**DynamoDB Streams** — একটি DynamoDB টেবিলের সমস্ত আইটেম পরিবর্তনের একটি সময়-ক্রমিক চেঞ্জ লগ। ইভেন্ট-চালিত প্রসেসিংয়ের জন্য Lambda-র সাথে ব্যবহৃত। অধ্যায় 9। ডোমেইন 2।

## E

**EBS (Elastic Block Store)** — একটি একক EC2 ইনস্ট্যান্সের সাথে সংযুক্ত ব্লক স্টোরেজ। স্বাধীনভাবে টিকে থাকে। টাইপ: gp3, io2, st1। অধ্যায় 6। ডোমেইন 3।

**EC2 (Elastic Compute Cloud)** — ক্লাউডে ভার্চুয়াল মেশিন। অধ্যায় 4। ডোমেইন 3।

**ECS (Elastic Container Service)** — পরিচালিত কন্টেইনার অর্কেস্ট্রেশন। Fargate লঞ্চ টাইপ সার্ভার ম্যানেজমেন্ট সরিয়ে দেয়। অধ্যায় 21। ডোমেইন 2, 3।

**EFS (Elastic File System)** — একাধিক EC2 ইনস্ট্যান্স থেকে অ্যাক্সেসযোগ্য ভাগ করা NFS ফাইল সিস্টেম। স্বয়ংক্রিয়ভাবে স্কেল করে। স্টোরেজ ক্লাসের মধ্যে রয়েছে Standard, Infrequent Access এবং Archive, টায়ারগুলির মধ্যে স্বয়ংক্রিয় চলাচলের জন্য Intelligent-Tiering সহ। অধ্যায় 6। ডোমেইন 3।

**EKS (Elastic Kubernetes Service)** — AWS-এ পরিচালিত Kubernetes কন্ট্রোল প্লেন। অধ্যায় 21। ডোমেইন 3।

**Elastic Disaster Recovery (DRS)** — সার্ভারের (অন-প্রিমিসেস বা EC2) একটানা ব্লক-স্তরের রেপ্লিকেশন একটি কম খরচের স্টেজিং এরিয়ায়, মিনিটে রিকভারি ইনস্ট্যান্স লঞ্চ সহ — একটি পরিচালিত pilot light। অধ্যায় 18। ডোমেইন 2।

**ElastiCache** — পরিচালিত ইন-মেমরি ক্যাশিং। Redis (সমৃদ্ধ বৈশিষ্ট্য) বা Memcached (সহজতর)। অধ্যায় 10। ডোমেইন 3।

**Elastic IP** — একটি স্ট্যাটিক পাবলিক IP অ্যাড্রেস যা আপনি বরাদ্দ করতে এবং EC2 ইনস্ট্যান্সের সাথে পুনরায় সংযুক্ত করতে পারেন। অধ্যায় 11। ডোমেইন 3।

**Envelope encryption** — একটি প্যাটার্ন যেখানে ডেটা একটি ডেটা কী (DEK) দিয়ে এনক্রিপ্ট করা হয়, এবং DEK একটি মাস্টার কী (KMS-এ CMK) দিয়ে এনক্রিপ্ট করা হয়। অধ্যায় 16। ডোমেইন 1।

**EventBridge** — AWS সার্ভিস, SaaS অংশীদার এবং কাস্টম সোর্স থেকে টার্গেটে ইভেন্ট রাউট করার জন্য ইভেন্ট বাস। শিডিউল করা নিয়ম সমর্থন করে। অধ্যায় 22। ডোমেইন 2।

**Explicit deny** — একটি IAM deny স্টেটমেন্ট যা কোনো allow দ্বারা ওভাররাইড করা যায় না। সমস্ত allow-এর উপর অগ্রাধিকার নেয়। অধ্যায় 3। ডোমেইন 1।

## F

**Failover রাউটিং (Route 53)** — প্রাইমারি স্বাস্থ্য পরীক্ষায় ব্যর্থ হলে একটি সেকেন্ডারি এন্ডপয়েন্টে ট্র্যাফিক রুট করে। অধ্যায় 12। ডোমেইন 2।

**Fargate** — ECS এবং EKS-এর জন্য সার্ভারলেস কম্পিউট ইঞ্জিন। পরিচালনার জন্য কোনো EC2 ইনস্ট্যান্স নেই। অধ্যায় 21। ডোমেইন 3।

**Fan-out প্যাটার্ন** — একটি SNS টপিক একই মেসেজ একসাথে একাধিক SQS কিউতে ডেলিভার করে। অধ্যায় 19। ডোমেইন 2।

**FIFO queue (SQS)** — Exactly-once প্রসেসিং, কঠোর অর্ডারিং। Standard কিউয়ের চেয়ে কম থ্রুপুট। অধ্যায় 19। ডোমেইন 2।

**Failure mode** — একটি নির্দিষ্ট উপায় যেভাবে একটি সিস্টেম ব্যর্থ হতে পারে। প্রোডাকশনের আগে ব্যর্থতা মোড শনাক্ত করা আর্কিটেকচার পর্যালোচনার মূল। অধ্যায় 32। ক্রস-ডোমেইন।

## G

**Gateway Endpoint** — S3 এবং DynamoDB-এর জন্য একটি বিনামূল্যে VPC এন্ডপয়েন্ট টাইপ। AWS প্রাইভেট নেটওয়ার্কের মাধ্যমে ট্র্যাফিক রুট করে, NAT Gateway চার্জ দূর করে। অধ্যায় 30। ডোমেইন 4।

**Gateway Load Balancer (GWLB)** — তৃতীয়-পক্ষের ভার্চুয়াল নেটওয়ার্ক অ্যাপ্লায়েন্স (ফায়ারওয়াল, IDS/IPS) ইনলাইন ট্র্যাফিক প্রবাহে সন্নিবেশের জন্য Layer 3 লোড ব্যালেন্সার। অধ্যায় 7। ডোমেইন 1।

**Geolocation রাউটিং (Route 53)** — DNS কোয়েরি উৎসের ভৌগোলিক অবস্থানের উপর ভিত্তি করে রুট করে। অধ্যায় 12। ডোমেইন 3।

**Global Accelerator** — Anycast-এর মাধ্যমে নিকটতম AWS এজে ট্র্যাফিক রুট করে, ডায়নামিক অ্যাপ্লিকেশনের জন্য লেটেন্সি উন্নত করে। অধ্যায় 25। ডোমেইন 3।

**Glue (AWS)** — সার্ভারলেস ETL। Glue Crawlers স্কিমা আবিষ্কার করে; Glue Jobs ডেটা রূপান্তর করে; Data Catalog মেটাডেটা সংরক্ষণ করে। অধ্যায় 26। ডোমেইন 3।

**GSI (Global Secondary Index)** — একটি ভিন্ন পার্টিশন কী এবং ঐচ্ছিক সর্ট কী সহ একটি DynamoDB টেবিলে একটি বিকল্প সূচী। নমনীয় কোয়েরি প্যাটার্ন সক্ষম করে। অধ্যায় 9। ডোমেইন 3।

**GuardDuty** — অস্বাভাবিক কার্যকলাপ সনাক্ত করতে CloudTrail, VPC Flow Logs এবং DNS লগে ML ব্যবহারকারী হুমকি সনাক্তকরণ সার্ভিস। অধ্যায় 17। ডোমেইন 1।

## H

**Health check (Route 53)** — এন্ডপয়েন্ট প্রাপ্যতা পর্যবেক্ষণ করে। ব্যর্থ স্বাস্থ্য পরীক্ষা failover রাউটিং ট্রিগার করে। অধ্যায় 12। ডোমেইন 2।

**Hot partition (DynamoDB)** — একটি পার্টিশন যা অসামঞ্জস্যপূর্ণ ট্র্যাফিক পায় কারণ অনেক অনুরোধ একই পার্টিশন কী ভাগ করে। অধ্যায় 9। ডোমেইন 3।

## I

**IAM (Identity and Access Management)** — AWS অ্যাকাউন্টের জন্য প্রমাণীকরণ এবং অনুমোদন নিয়ন্ত্রণ করে। ব্যবহারকারী, গ্রুপ, রোল, পলিসি। অধ্যায় 3, 14। ডোমেইন 1।

**IAM role** — অস্থায়ী ক্রেডেনশিয়াল সহ একটি IAM আইডেন্টিটি, সার্ভিস, ব্যবহারকারী বা অন্যান্য অ্যাকাউন্ট দ্বারা গৃহীত। অধ্যায় 3, 14। ডোমেইন 1।

**Idempotency** — একটি অপারেশনের বৈশিষ্ট্য যা একবার বা বহুবার কল করা হোক একই ফলাফল উৎপন্ন করে। বিতরণকৃত সিস্টেমের জন্য সমালোচনামূলক (রিফান্ড, পেমেন্ট, অর্ডার প্রসেসিং)। অধ্যায় 32। ক্রস-ডোমেইন।

**Idempotency key** — একটি অপারেশনের জন্য একটি অনন্য শনাক্তকারী, ডুপ্লিকেট প্রসেসিং প্রতিরোধ করতে এক্সিকিউশনের আগে পরীক্ষা করা হয়। অধ্যায় 32। ক্রস-ডোমেইন।

**Interface Endpoint (PrivateLink)** — বেশিরভাগ AWS সার্ভিসের জন্য একটি VPC এন্ডপয়েন্ট। প্রতি ঘণ্টা + প্রতি GB মূল্য। ইন্টারনেট বা NAT ছাড়াই প্রাইভেট সংযোগ প্রদান করে। অধ্যায় 30। ডোমেইন 4।

**Internet Gateway (IGW)** — পাবলিক সাবনেটে ইনস্ট্যান্সগুলিকে ইন্টারনেটের সাথে যোগাযোগ করতে দেয়। সাবনেটের রুট টেবিলে IGW-তে একটি রুট থাকা প্রয়োজন। অধ্যায় 11। ডোমেইন 3।

**"It depends"** — বেশিরভাগ আর্কিটেকচার প্রশ্নের সৎ উত্তর, যা সর্বদা সম্পূর্ণ করতে হবে: "এটি অ্যাক্সেস প্যাটার্ন / স্কেল / ব্যর্থতার পরিণতি / খরচ সীমাবদ্ধতার উপর নির্ভর করে।" অধ্যায় 33। ক্রস-ডোমেইন।

## K

**Kinesis Data Firehose** — Amazon Data Firehose-এর পূর্ববর্তী নাম: S3, Redshift, OpenSearch-এ স্ট্রিমিং ডেটার পরিচালিত ডেলিভারি। কোনো কনজিউমার ম্যানেজমেন্ট নেই। পুরোনো পরীক্ষার প্রশ্ন এখনও পুরোনো নাম ব্যবহার করতে পারে। অধ্যায় 26। ডোমেইন 3।

**Kinesis Data Streams** — রিয়েল-টাইম ক্রমিক ইভেন্ট স্ট্রিম। টেকসই, রিটেনশন উইন্ডোর মধ্যে রিপ্লেযোগ্য (ডিফল্ট 24 ঘণ্টা, 365 দিন পর্যন্ত)। shard-এ মাপা। অধ্যায় 26। ডোমেইন 3।

**KMS (Key Management Service)** — বিশ্রামে এনক্রিপশনের জন্য ক্রিপ্টোগ্রাফিক কী তৈরি, সংরক্ষণ এবং নিয়ন্ত্রণ করে। অধ্যায় 16। ডোমেইন 1।

## L

**Lambda** — ইভেন্ট দ্বারা ট্রিগার হওয়া সার্ভারলেস ফাংশন। প্রতি ইনভোকেশন এবং প্রতি ms-এ দেন। সর্বোচ্চ 15-মিনিট সময়কাল। অধ্যায় 20। ডোমেইন 2, 3, 4।

**Lambda@Edge** — Lambda ফাংশন যা CloudFront এজ লোকেশনে চলে, অনুরোধ এবং প্রতিক্রিয়া পরিবর্তন করে। অধ্যায় 13। ডোমেইন 3।

**AWS Lake Formation** — S3 এবং Glue Data Catalog-এর উপরে কেন্দ্রীভূত ডেটা লেক অ্যাক্সেস নিয়ন্ত্রণ লেয়ার। টেবিল, কলাম এবং রো স্তরে সূক্ষ্ম-দানাদার অনুমতি প্রদান করে। নিরাপদ ডেটা লেক সেটআপ সহজ করে। অধ্যায় 26। ডোমেইন 3।

**Latency-based রাউটিং (Route 53)** — সর্বনিম্ন পরিমাপকৃত লেটেন্সি সহ AWS অঞ্চলে DNS কোয়েরি রুট করে। অধ্যায় 12। ডোমেইন 3।

**Launch template** — Auto Scaling Groups-এর জন্য EC2 ইনস্ট্যান্স কনফিগারেশন নির্দিষ্ট করে এমন একটি ভার্সনযুক্ত টেমপ্লেট। অধ্যায় 7। ডোমেইন 3।

**Least privilege** — IAM সর্বোত্তম অনুশীলন: শুধুমাত্র প্রয়োজনীয় অনুমতি প্রদান করুন, তার বেশি নয়। অধ্যায় 3। ডোমেইন 1।

**Lifecycle policy (S3)** — নিয়ম যা বয়সের উপর ভিত্তি করে অবজেক্টগুলিকে স্বয়ংক্রিয়ভাবে সস্তা স্টোরেজ ক্লাসে ট্রানজিশন করে বা মুছে দেয়। অধ্যায় 23। ডোমেইন 4।

**LSI (Local Secondary Index)** — একই পার্টিশন কী কিন্তু একটি ভিন্ন সর্ট কী ব্যবহার করে একটি DynamoDB টেবিলে একটি বিকল্প সূচী। টেবিল তৈরির সময় অবশ্যই তৈরি করতে হবে। অধ্যায় 9। ডোমেইন 3।

## M

**Amazon Macie** — S3-তে সংবেদনশীল ডেটা (PII) এর ML-ভিত্তিক আবিষ্কার এবং এক্সপোজার ঝুঁকি চিহ্নিতকরণ। GuardDuty আচরণ দেখে; Macie কী সংরক্ষিত আছে তা অডিট করে। অধ্যায় 17। ডোমেইন 1।

**Memcached** — সহজ, মাল্টি-থ্রেডেড ইন-মেমরি ক্যাশিং ইঞ্জিন। কোনো স্থায়িত্ব নেই, কোনো ডেটা স্ট্রাকচার নেই। বৈশিষ্ট্যের খরচে আপনার বিশেষভাবে মাল্টি-থ্রেডিং প্রয়োজন না হলে Redis ব্যবহার করুন। অধ্যায় 10। ডোমেইন 3।

**Amazon MemoryDB for Redis** — টেকসই, Redis-সামঞ্জস্যপূর্ণ, ইন-মেমরি প্রাইমারি ডেটাবেস। ElastiCache-এর বিপরীতে, MemoryDB একটি Multi-AZ ট্রানজেকশন লগে লেখে, ডেটা স্থায়িত্বের নিশ্চয়তা দেয়। Redis API সামঞ্জস্যতা প্রয়োজন এবং ডেটা হারানো গ্রহণযোগ্য নয় এমন ক্ষেত্রে ব্যবহার করুন। অধ্যায় 10। ডোমেইন 3।

**MGN (AWS Application Migration Service)** — রিহোস্ট/lift-and-shift: সম্পূর্ণ সার্ভারের AWS-এ ব্লক-স্তরের রেপ্লিকেশন, টেস্ট লঞ্চ, তারপর নেটিভ EC2 ইনস্ট্যান্সে কাটওভার। DataSync ফাইল সরায়; DMS ডেটাবেস সরায়; MGN সার্ভার সরায়। অধ্যায় 25। ডোমেইন 3।

**Amazon MQ** — মানক প্রোটোকল (AMQP, MQTT, STOMP) বলা পরিচালিত ActiveMQ/RabbitMQ ব্রোকার। কোড পরিবর্তন ছাড়াই বিদ্যমান ব্রোকার ওয়ার্কলোডের lift-and-shift-এর জন্য; গ্রিনফিল্ড মেসেজিং → SQS/SNS। অধ্যায় 19। ডোমেইন 2।

**Multi-AZ (RDS)** — স্বয়ংক্রিয় ফেলওভার সহ একটি ভিন্ন AZ-এ সিঙ্ক্রোনাস স্ট্যান্ডবাই রেপ্লিকা। RPO ~0, RTO ~60 সেকেন্ড। উচ্চ প্রাপ্যতার জন্য, রিড স্কেলিংয়ের জন্য নয়। অধ্যায় 8, 18। ডোমেইন 2।

**Multi-Region** — ভৌগোলিক রিডানডেন্সি এবং গ্লোবাল পারফরম্যান্সের জন্য একাধিক AWS অঞ্চল জুড়ে অ্যাপ্লিকেশন উপাদান স্থাপন। উচ্চতর জটিলতা এবং খরচ। অধ্যায় 18। ডোমেইন 2।

---

## N

**Network Load Balancer (NLB)** — Layer 4 (TCP/UDP/TLS) লোড ব্যালেন্সার: প্রতি সেকেন্ডে লক্ষ লক্ষ অনুরোধ, প্রতি AZ-এ স্ট্যাটিক IP, সোর্স IP সংরক্ষণ করে। কোনো HTTP সচেতনতা নেই — সেটা ALB-র কাজ। অধ্যায় 7। ডোমেইন 3।

**NACL (Network Access Control List)** — সাবনেট স্তরে stateless ফায়ারওয়াল। ইনবাউন্ড এবং আউটবাউন্ড উভয় নিয়ম প্রয়োজন। নিয়ম সাংখ্যিক ক্রমে মূল্যায়ন করা হয়। অধ্যায় 15। ডোমেইন 1।

**NAT Gateway** — প্রাইভেট সাবনেটে ইনস্ট্যান্সগুলিকে ইন্টারনেটে আউটবাউন্ড সংযোগ করতে দেয়। প্রসেস করা প্রতি $0.045/GB চার্জ করে। অধ্যায় 11, 30। ডোমেইন 4।

---

## O

**Object (S3)** — S3-তে সংরক্ষিত একটি ফাইল। কী (নাম), ভ্যালু (ডেটা) এবং মেটাডেটা নিয়ে গঠিত। সর্বোচ্চ সাইজ 5TB। অধ্যায় 5। ডোমেইন 3।

**On-Demand capacity (DynamoDB)** — প্রতি অনুরোধে দেওয়ার মোড। provisioned-এর চেয়ে প্রতি অনুরোধে বেশি ব্যয়বহুল, কিন্তু কোনো ক্যাপাসিটি পরিকল্পনা প্রয়োজন নেই। অধ্যায় 29। ডোমেইন 4।

**On-Demand instances (EC2)** — কোনো প্রতিশ্রুতি ছাড়াই প্রতি ঘণ্টায় দেন। সর্বাধিক নমনীয়তা, সর্বাধিক মূল্য। অধ্যায় 27। ডোমেইন 4।

**AWS Outposts** — একটি গ্রাহকের নিজস্ব ডেটা সেন্টার বা কো-লোকেশন সুবিধায় ইনস্টল করা AWS হার্ডওয়্যারের একটি সম্পূর্ণরূপে পরিচালিত র‍্যাক। পাবলিক ক্লাউডের মতো একই AWS সার্ভিস, API এবং টুলিং অন-প্রিমিসেস চালায়। AWS ইনস্টলেশন এবং প্যাচিং পরিচালনা করে; গ্রাহক র‍্যাক স্পেস এবং পাওয়ার সরবরাহ করে। ডেটা রেসিডেন্সি, লো-লেটেন্সি অন-প্রিমিসেস ওয়ার্কলোড বা সংযোগবিচ্ছিন্ন পরিস্থিতির জন্য। অধ্যায় 2। ডোমেইন 4।

---

## P

**Partition key (DynamoDB)** — প্রাইমারি কী উপাদান যা নির্ধারণ করে কোন পার্টিশন একটি আইটেম সংরক্ষণ করে। সমান বিতরণের জন্য একটি হাই-কার্ডিনালিটি কী বেছে নিন। অধ্যায় 9। ডোমেইন 3।

**Permission boundary** — একটি IAM পলিসি যা একটি IAM আইডেন্টিটির সর্বোচ্চ অনুমতি নির্ধারণ করে, এমনকি অন্যান্য পলিসি বেশি প্রদান করলেও। অধ্যায় 14। ডোমেইন 1।

**Placement group** — লেটেন্সি কমাতে (cluster) বা প্রাপ্যতা সর্বাধিক করতে (spread) EC2 ইনস্ট্যান্সের শারীরিক স্থাপন নিয়ন্ত্রণ করে। অধ্যায় 4। ডোমেইন 3।

**PrivateLink** — AWS-এ হোস্ট করা সার্ভিসে প্রাইভেট এন্ডপয়েন্ট তৈরির জন্য AWS সার্ভিস, Interface Endpoints-এর মাধ্যমে অ্যাক্সেসযোগ্য। অধ্যায় 30। ডোমেইন 1।

**Provisioned concurrency (Lambda)** — পূর্ব-ইনিশিয়ালাইজড এক্সিকিউশন এনভায়রনমেন্ট যা কোল্ড স্টার্ট বিলম্ব দূর করে। অধ্যায় 20। ডোমেইন 3।

**Provisioned capacity (DynamoDB)** — পূর্ব-বরাদ্দ করা read এবং write থ্রুপুট, প্রতি সেকেন্ডে ক্যাপাসিটি ইউনিটে মাপা। পূর্বানুমেয় ট্র্যাফিকের জন্য on-demand-এর চেয়ে সস্তা। অধ্যায় 9, 29। ডোমেইন 4।

## Q

**Amazon QuickSight** — পরিচালিত বিজনেস ইন্টেলিজেন্স এবং ডেটা ভিজ্যুয়ালাইজেশন সার্ভিস। দ্রুত ড্যাশবোর্ড রেন্ডারিংয়ের জন্য ডেটা ক্যাশ করতে SPICE (Super-fast, Parallel, In-memory Calculation Engine) ব্যবহার করে। Athena, S3, Redshift, RDS এবং অন্যান্য AWS ডেটা সোর্সের সাথে সংযুক্ত হয়। পরিচালনার জন্য কোনো BI সার্ভার নেই। অধ্যায় 26। ডোমেইন 3।

---

## R

**RDS (Relational Database Service)** — পরিচালিত রিলেশনাল ডেটাবেস। ব্যাকআপ, প্যাচিং, ফেলওভার পরিচালনা করে। অধ্যায় 8। ডোমেইন 3।

**RDS Proxy** — Lambda/অ্যাপ্লিকেশন এবং RDS-এর মধ্যে একটি কানেকশন পুল পরিচালনা করে, কানেকশন নিঃশেষ হওয়া প্রতিরোধ করে। অধ্যায় 8। ডোমেইন 3।

**Read Replica (RDS)** — রিড স্কেলিংয়ের জন্য ডেটাবেসের অ্যাসিঙ্ক্রোনাস কপি। স্বয়ংক্রিয় ফেলওভার প্রদান করে না। অধ্যায় 8, 24। ডোমেইন 3।

**Redis** — ক্যাশিং, সেশন ম্যানেজমেন্ট, রিয়েল-টাইম লিডারবোর্ড, pub/sub-এর জন্য ব্যবহৃত ইন-মেমরি ডেটা স্ট্রাকচার স্টোর। অধ্যায় 10। ডোমেইন 3।

**Reserved Instance (EC2)** — একটি ছাড়ের বিনিময়ে 1 বা 3 বছরের জন্য একটি নির্দিষ্ট অঞ্চলে একটি নির্দিষ্ট ইনস্ট্যান্স টাইপ ব্যবহারের প্রতিশ্রুতি। অধ্যায় 27। ডোমেইন 4।

**Route 53** — AWS DNS সার্ভিস এবং ডোমেইন রেজিস্ট্রার। একাধিক রাউটিং পলিসি সমর্থন করে। অধ্যায় 12। ডোমেইন 2, 3।

**RPO (Recovery Point Objective)** — সময়ে মাপা সর্বাধিক গ্রহণযোগ্য ডেটা হারানো। "আমরা কতটা ডেটা হারাতে পারি?" অধ্যায় 18। ডোমেইন 2।

**RTO (Recovery Time Objective)** — একটি ব্যর্থতার পরে সার্ভিস পুনরুদ্ধারের সর্বাধিক গ্রহণযোগ্য সময়। "আমরা কতক্ষণ ডাউন থাকতে পারি?" অধ্যায় 18। ডোমেইন 2।

**Runbook** — একটি সিস্টেম পরিচালনার জন্য ধাপে ধাপে নির্দেশনা, বিশেষভাবে ঘটনা প্রতিক্রিয়ার জন্য। "রাত 3টায় কেউ কী করে?" অধ্যায় 32। ক্রস-ডোমেইন।

---

## S

**S3 Intelligent-Tiering** — অ্যাক্সেস প্যাটার্নের উপর ভিত্তি করে স্বয়ংক্রিয়ভাবে S3 অবজেক্টগুলিকে অ্যাক্সেস টায়ারের মধ্যে সরায়। কোনো পুনরুদ্ধার ফি নেই। অধ্যায় 23। ডোমেইন 4।

**S3 Select** — SQL এক্সপ্রেশন ব্যবহার করে একটি S3 অবজেক্ট কন্টেন্টের একটি উপসেট পুনরুদ্ধার করে, ডেটা ট্রান্সফার কমায়। লিগ্যাসি: 2024-এর মাঝামাঝি থেকে নতুন গ্রাহকদের জন্য অনুপলব্ধ — Athena এখন S3-তে ডেটা ফিল্টার এবং কোয়েরি করার প্রাথমিক পথ। S3 Object Lambda, একসময় প্রস্তাবিত বিকল্প, নিজেই লিগ্যাসি (নভেম্বর 2025-এ নতুন গ্রাহকদের জন্য বন্ধ; বিদ্যমান ওয়ার্কলোড কাজ করতে থাকে)। অধ্যায় 30। ডোমেইন 4।

**Savings Plan** — একটি ছাড়ের বিনিময়ে ঘণ্টায় ব্যয়ের একটি ডলার পরিমাণে প্রতিশ্রুতি দেওয়া একটি নমনীয় মূল্য নির্ধারণ মডেল। Reserved Instances-এর চেয়ে আরও নমনীয়। অধ্যায় 27। ডোমেইন 4।

**SCP (Service Control Policy)** — AWS Organizations পলিসি যা একটি OU-তে অ্যাকাউন্টগুলির জন্য উপলব্ধ সর্বোচ্চ অনুমতি সীমাবদ্ধ করে। অধ্যায় 14। ডোমেইন 1।

**Secrets Manager** — সিক্রেট (ডেটাবেস পাসওয়ার্ড, API কী) সংরক্ষণ এবং স্বয়ংক্রিয়ভাবে রোটেট করে। অধ্যায় 16। ডোমেইন 1।

**Security group** — ইনস্ট্যান্স স্তরে একটি stateful ভার্চুয়াল ফায়ারওয়াল। শুধুমাত্র অনুমতির নিয়ম; রিটার্ন ট্র্যাফিক স্বয়ংক্রিয়। অধ্যায় 15। ডোমেইন 1।

**Shard (Kinesis)** — Kinesis Data Streams-এ থ্রুপুটের বেস ইউনিট: 1 MB/s রাইট, 2 MB/s রিড। অধ্যায় 26। ডোমেইন 3।

**Shared Responsibility Model** — AWS ক্লাউডের নিরাপত্তার *জন্য* দায়ী (অবকাঠামো); আপনি ক্লাউডের *মধ্যে* নিরাপত্তার জন্য দায়ী (ডেটা, কনফিগারেশন, অ্যাক্সেস)। অধ্যায় 1। ডোমেইন 1।

**Shield** — DDoS সুরক্ষা। Standard: বিনামূল্যে, স্বয়ংক্রিয়। Advanced: অর্থপ্রদান, DRT সমর্থন এবং আর্থিক সুরক্ষা সহ। অধ্যায় 17। ডোমেইন 1।

**Snow Family** — অফলাইন বাল্ক ডেটা ট্রান্সফারের জন্য শারীরিক ডিভাইস (Snowball Edge: 80 TB) — হাইওয়েতে গাড়ি চালানোর পরিবর্তে একটি কার্গো ফ্লাইট ভাড়া করা। লিগ্যাসি (2026): Snowmobile এবং Snowcone বন্ধ; Snow ডিভাইস নভেম্বর 2025-এ নতুন গ্রাহকদের জন্য বন্ধ (AWS DataSync এবং Data Transfer Terminals-এর দিকে নির্দেশ করে), কিন্তু SAA-C03 পরীক্ষা এখনও "সপ্তাহের ট্রান্সফার, সীমিত ব্যান্ডউইথ" এর জন্য Snowball আশা করে। অধ্যায় 25। ডোমেইন 3।

**SNS (Simple Notification Service)** — Pub/sub মেসেজিং। একসাথে সমস্ত সাবস্ক্রাইবারে মেসেজ পুশ করে। Fan-out প্যাটার্ন। অধ্যায় 19। ডোমেইন 2।

**Sort key (DynamoDB)** — প্রাইমারি কী-এর ঐচ্ছিক দ্বিতীয় উপাদান। একটি পার্টিশনের মধ্যে রেঞ্জ কোয়েরি সক্ষম করে। অধ্যায় 9। ডোমেইন 3।

**Spot Instances** — 60-90% ছাড়ে স্পেয়ার ক্যাপাসিটি ব্যবহারকারী EC2 ইনস্ট্যান্স। 2-মিনিট নোটিশে বিঘ্নিত হতে পারে। শুধুমাত্র ফল্ট-টলারেন্ট ওয়ার্কলোডের জন্য। অধ্যায় 27। ডোমেইন 4।

**SQS (Simple Queue Service)** — পরিচালিত মেসেজ কিউ। প্রোডিউসারদের কনজিউমার থেকে ডিকাপল করে। Standard (at-least-once) এবং FIFO (exactly-once) কিউ। অধ্যায় 19। ডোমেইন 2।

**Step Functions** — সার্ভারলেস ওয়ার্কফ্লো অর্কেস্ট্রেশন সার্ভিস। AWS সার্ভিস সমন্বয়ের জন্য স্টেট মেশিন। অধ্যায় 22। ডোমেইন 2।

**AWS Storage Gateway** — অন-প্রিমিসেস এবং ক্লাউড স্টোরেজের মধ্যে সেতু: স্থানীয়ভাবে NFS/SMB (File), iSCSI (Volume), বা ভার্চুয়াল টেপ (Tape) ইন্টারফেস উপস্থাপন করে যখন S3, Glacier, বা EBS স্ন্যাপশটে ডেটা স্থায়ী করে। অধ্যায় 6। ডোমেইন 3।

---

## T

**Target tracking scaling** — Auto Scaling পলিসি যা একটি টার্গেট মেট্রিক মান (যেমন 60% CPU ব্যবহার) বজায় রাখতে ক্যাপাসিটি সামঞ্জস্য করে। অধ্যায় 7। ডোমেইন 2।

**AWS Transfer Family** — S3 বা EFS দ্বারা সমর্থিত পরিচালিত SFTP/FTPS/FTP এন্ডপয়েন্ট। অংশীদাররা তাদের বিদ্যমান SFTP ক্লায়েন্ট রাখে; ফাইল সরাসরি আপনার বাকেটে অবতরণ করে। অধ্যায় 25। ডোমেইন 3।

**Transit Gateway** — একটি কেন্দ্রীয় গেটওয়ের মাধ্যমে একাধিক VPC এবং অন-প্রিমিসেস নেটওয়ার্ক সংযুক্ত করা হাব-অ্যান্ড-স্পোক নেটওয়ার্ক টপোলজি। অধ্যায় 25। ডোমেইন 3।

**TTL (Time to Live)** — একটি টাইমস্ট্যাম্প যার পরে DynamoDB স্বয়ংক্রিয়ভাবে একটি আইটেম মুছে দেয়। DNS-এও ব্যবহৃত (রিজলভার কতক্ষণ একটি রেকর্ড ক্যাশ করে) এবং ক্যাশিং (একটি ক্যাশড মান কতক্ষণ বৈধ)। অধ্যায় 9, 12। ডোমেইন 3।

---

## V

**VIF (Virtual Interface)** — AWS Direct Connect-এর সাথে ব্যবহৃত লজিক্যাল সংযোগ। Public VIF AWS পাবলিক এন্ডপয়েন্ট অ্যাক্সেস করে; Private VIF VPC রিসোর্স অ্যাক্সেস করে। অধ্যায় 25। ডোমেইন 3।

**Visibility timeout (SQS)** — সময়কাল যার মধ্যে একটি গৃহীত মেসেজ অন্য কনজিউমার থেকে লুকানো থাকে। অন্য কনজিউমাররা একই মেসেজ না দেখে প্রসেসিং করার অনুমতি দেয়। অধ্যায় 19। ডোমেইন 2।

**VPC (Virtual Private Cloud)** — AWS-এ একটি বিচ্ছিন্ন ভার্চুয়াল নেটওয়ার্ক। সাবনেট, রুট টেবিল এবং গেটওয়ে ধারণ করে। অধ্যায় 11। ডোমেইন 1।

**VPC Endpoint** — AWS প্রাইভেট নেটওয়ার্কের মাধ্যমে VPC রিসোর্সকে AWS সার্ভিসের সাথে সংযুক্ত করে। Gateway (বিনামূল্যে, S3/DynamoDB) এবং Interface (মূল্যযুক্ত, বেশিরভাগ অন্যান্য সার্ভিস)। অধ্যায় 30। ডোমেইন 1, 4।

**VPC Flow Logs** — একটি VPC-তে নেটওয়ার্ক ইন্টারফেসে যাওয়া-আসা IP ট্র্যাফিক সম্পর্কে তথ্য ক্যাপচার করে। GuardDuty দ্বারা এবং নেটওয়ার্ক সমস্যা সমাধানের জন্য ব্যবহৃত। অধ্যায় 17। ডোমেইন 1।

**VPC Peering** — দুটি VPC-এর মধ্যে একটি নেটওয়ার্ক সংযোগ যা প্রাইভেট IP অ্যাড্রেস ব্যবহার করে তাদের মধ্যে ট্র্যাফিক রুট করতে সক্ষম করে। অধ্যায় 11। ডোমেইন 3।

---

## W

**WAF (Web Application Firewall)** — নিয়ম (IP ব্লক, SQL injection, রেট লিমিট) ব্যবহার করে HTTP/HTTPS ট্র্যাফিক ফিল্টার করে। CloudFront, ALB, বা API Gateway-এর সাথে সংযুক্ত হয়। অধ্যায় 17। ডোমেইন 1।

**AWS Wavelength** — রেডিও এজে 5G টেলিকমিউনিকেশন প্রদানকারীদের নেটওয়ার্কের ভিতরে স্থাপিত AWS অবকাঠামো। মোবাইল ডিভাইসে একক-সংখ্যা মিলিসেকেন্ড লেটেন্সি সক্ষম করে। মোবাইল AR/VR, রিয়েল-টাইম গেমিং, স্বয়ংক্রিয় যানবাহন টেলিমেট্রি এবং 5G এজে লাইভ ভিডিওর জন্য। Wavelength Zones হল টেলিকম নেটওয়ার্কের মধ্যে AWS Regions-এর সম্প্রসারণ। অধ্যায় 2। ডোমেইন 3।

**Well-Architected Framework** — AWS-এর ছয়-স্তম্ভ মূল্যায়ন কাঠামো: Operational Excellence, Security, Reliability, Performance Efficiency, Cost Optimization, Sustainability। অধ্যায় 31। ক্রস-ডোমেইন।

**Weighted routing (Route 53)** — ওজন অনুসারে এন্ডপয়েন্ট জুড়ে DNS কোয়েরি বিতরণ করে। ব্লু-গ্রিন ডিপ্লয়মেন্ট এবং A/B টেস্টিংয়ের জন্য ব্যবহৃত। অধ্যায় 12। ডোমেইন 3।

**Write-through caching** — যখনই ডেটাবেস আপডেট হয় তখনই ক্যাশ আপডেট করে। ডেটা সর্বদা সামঞ্জস্যপূর্ণ কিন্তু ক্যাশে অনেক আইটেম থাকতে পারে যা কখনও পুনরায় পড়া হয় না। অধ্যায় 10। ডোমেইন 3।

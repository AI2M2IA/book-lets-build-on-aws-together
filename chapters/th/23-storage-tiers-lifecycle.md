# บทที่ 23: ระบบจัดเก็บเอกสารที่เรียงตัวเอง

S3 ทำสิ่งนี้โดยอัตโนมัติ

Tom กำลังตรวจสอบบิล S3: $847/เดือน

"ครั้งสุดท้ายที่ใครเข้าถึงการสำรองข้อมูลจาก 18 เดือนที่แล้วคือเมื่อไหร่?" Tom ถาม

Leo ตรวจสอบ access logs "ตุลาคมปีที่แล้ว ครั้งเดียว เพื่อยืนยันรูปแบบการสำรองข้อมูล"

**S3 Storage Classes: สเปกตรัมเต็ม**

**S3 Standard**: สำหรับข้อมูลที่เข้าถึงบ่อย Latency ต่ำ

**S3 Standard-Infrequent Access (S3 Standard-IA)**: สำหรับข้อมูลที่เข้าถึงน้อยกว่าครั้งต่อเดือน การดึงข้อมูลทันที ต้นทุนการจัดเก็บต่ำกว่า

**S3 Glacier Instant Retrieval**: ข้อมูลเก็บถาวรที่เข้าถึงบางครั้ง การดึงข้อมูลทันที ต้นทุนการจัดเก็บต่ำมาก

**S3 Glacier Deep Archive**: ถูกที่สุด ดึงข้อมูลภายใน 12 ชั่วโมง

**S3 Lifecycle Policies: ระบบจัดเก็บอัตโนมัติ**

**Lifecycle policies** ทำการเปลี่ยนแปลงเหล่านี้โดยอัตโนมัติตามกฎ

ตัวอย่าง lifecycle policy สำหรับใบเสร็จออร์เดอร์ของ Nimbus:

```
เปลี่ยนเป็น S3 Standard-IA หลังจาก 90 วัน
เปลี่ยนเป็น S3 Glacier Instant Retrieval หลังจาก 365 วัน
เปลี่ยนเป็น S3 Glacier Deep Archive หลังจาก 2555 วัน (7 ปี)
ลบหลังจาก 2920 วัน (8 ปี)
```

Tom ตรวจสอบการประหยัดที่คาดการณ์: จาก $847/เดือนเป็นประมาณ $220/เดือน

"แค่กำหนดสิ่งที่เก่าและควรไปที่ไหน?" เขาพูด

"และ S3 ย้ายมันโดยอัตโนมัติ" Leo ยืนยัน

## สรุป

- S3 มีเจ็ด storage classes: Standard, Standard-IA, Intelligent-Tiering, One Zone-IA, Glacier Instant Retrieval, Glacier Flexible Retrieval และ Glacier Deep Archive
- **Lifecycle policies** ทำให้การเปลี่ยน storage classes เป็นอัตโนมัติตามอายุ
- **S3 Intelligent-Tiering** ย้าย objects ระหว่าง tiers โดยอัตโนมัติตามรูปแบบการเข้าถึงจริง
- **S3 Object Lock** ให้ WORM storage สำหรับสถานการณ์การปฏิบัติตาม

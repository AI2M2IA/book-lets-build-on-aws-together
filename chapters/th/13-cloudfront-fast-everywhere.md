**การเปรียบเปรยกับคลังสินค้าที่เตรียมไว้ล่วงหน้า**

Amazon (ผู้ค้าปลีก) มีคลังสินค้าขนาดใหญ่ที่มีทุกผลิตภัณฑ์ แทนที่จะส่งทุกออร์เดอร์จากคลังเดียว Amazon มีศูนย์กระจายสินค้าใกล้ประชากรหลัก เมื่อลูกค้าในซีแอตเทิลสั่งซื้อ มันถูกส่งจากศูนย์กระจายสินค้าในท้องถิ่น

นี่คือ **Content Delivery Network (CDN)**: เครือข่ายเซิร์ฟเวอร์ที่กระจายทางภูมิศาสตร์ที่แคชสำเนาเนื้อหาของคุณใกล้กับผู้ใช้

**พบกับ CloudFront**

Amazon CloudFront คือ CDN ของ AWS ทำงานผ่านเครือข่ายทั่วโลกของ **edge locations** — เซิร์ฟเวอร์ caching ที่วางอยู่ในเมืองต่างๆ ทั่วโลก

เมื่อคุณกำหนดค่า CloudFront คุณระบุ **origin**: แหล่งเนื้อหาจริงของคุณ

CloudFront นั่งอยู่หน้า origin ของคุณ คำขอมาถึงที่ edge location ที่ใกล้ที่สุด ถ้า edge มีเนื้อหา cached มันส่งคืนทันที ถ้าไม่ (*cache miss*) มันดึงจาก origin แคชมัน และส่งคืน

## สรุป

- **CDN** แคชสำเนาเนื้อหาของคุณที่ edge locations ใกล้กับผู้ใช้
- **CloudFront** คือ CDN ของ AWS มีมากกว่า 500 edge locations ทั่วโลก
- Cache misses ดึงจาก **origin** (S3, ALB, EC2) Cache hits ให้บริการจาก edge
- **Behaviors** ช่วยให้คุณตั้งกฎ caching ที่แตกต่างกันสำหรับรูปแบบ URL ที่แตกต่างกัน
- **Origin Access Control** จำกัดการเข้าถึง S3 โดยตรง — เนื้อหาถูกให้บริการผ่าน CloudFront เท่านั้น

## เคล็ดลับการสอบ

- **CloudFront + S3**: รูปแบบการสอบคลาสสิกสำหรับการให้บริการเว็บไซต์แบบ static ทั่วโลก
- **Edge locations กับ Regions กับ AZs**: Edge locations มีมากกว่าและมีอยู่เพื่อวัตถุประสงค์ caching/CDN เท่านั้น
- **Signed URLs และ Signed Cookies**: ควบคุมว่าใครสามารถเข้าถึงเนื้อหาผ่าน CloudFront

**AWS Lambda: Code โดยไม่มีเซิร์ฟเวอร์**

**AWS Lambda** ให้คุณรัน code ตอบสนองต่อเหตุการณ์โดยไม่ต้องจัดหาหรือจัดการเซิร์ฟเวอร์

Lambda function:

- ไม่มี persistent state
- รันสูงสุด 15 นาทีต่อ invocation
- ขยายขนาดโดยอัตโนมัติจาก 0 ถึงหลายพัน concurrent invocations
- เรียกเก็บเงินเฉพาะเมื่อทำงาน (ต่อ 1ms ของการทำงาน)

**Event Triggers**

Triggers ทั่วไปได้แก่: SQS queue, API Gateway, S3 event, SNS, DynamoDB Streams, EventBridge

**ปัญหา Cold Start**

เมื่อ function ถูกเรียก:

1. AWS ตรวจสอบว่ามี warm execution environment ว่างหรือไม่
2. ถ้าอุ่น: function รันทันที
3. ถ้าเย็น: AWS เริ่มต้น execution environment ใหม่ — ดาวน์โหลด code เริ่ม runtime — แล้วรัน function

**Cold start** เพิ่ม 100ms ถึงไม่กี่วินาทีของ latency

**ราคา Lambda**

สองส่วนประกอบ:

1. **ค่า request**: $0.20 ต่อล้าน invocations
2. **ค่าระยะเวลา**: $0.0000166667 ต่อ GB-second

ล้าน request แรกต่อเดือนฟรี (ตลอดไป)

## สรุป

- **AWS Lambda** รัน code ตอบสนองต่อเหตุการณ์โดยไม่จัดการเซิร์ฟเวอร์
- **จ่ายตามการใช้งาน**: เรียกเก็บเงินต่อ invocation และต่อ 1ms ของการทำงาน ศูนย์ค่าใช้จ่ายเมื่อไม่ได้ใช้งาน
- ขยายขนาดโดยอัตโนมัติจาก 0 ถึงหลายพัน concurrent invocations
- **Cold starts**: latency การเริ่มต้นเมื่อไม่มี warm execution environment
- เหมาะที่สุดสำหรับ: event-driven processing งานระยะสั้น traffic ไม่สม่ำเสมอ
- ไม่เหมาะสำหรับ: กระบวนการที่ใช้เวลานาน (จำกัด 15 นาที) แอปพลิเคชันที่มี state

# פרק 17: השומרים

האירוע עם ה-IP הרומני הוכל. Priya שאלה: "אם משהו חריג יופיע ביומני CloudTrail, כיצד נדע?"

התשובה הכנה הייתה: כנראה לא.

CloudTrail רושם אלפי אירועים ביום. שום אדם לא קורא את כולם.

"אנחנו צריכים משהו שעוקב אחרי היומנים עבורנו," אמרה.

**שלוש קטגוריות איומים**

איומי אבטחה כנגד יישום ענן נופלים לשלוש קטגוריות:

**מתקפות נפח (DDoS)**: תוקף שולח כל כך הרבה תנועה שהיישום לא יכול להגיב ללקוחות לגיטימיים.

**מתקפות יישום (ניצול)**: תוקף שולח בקשות מעוצבות ספציפית לניצול חולשות — SQL injection, cross-site scripting, קלט מעוות.

**אנומליות התנהגות (ריקון ופגיעה)**: קריאות API שלא צריכות לקרות, פעילות IAM חריגה.

ל-AWS יש שירות ייעודי לכל אחת:

- **AWS Shield**: הגנה מפני DDoS
- **AWS WAF**: הגנה ברמת יישום
- **Amazon GuardDuty**: זיהוי איומים התנהגותי

**AWS Shield: ספג DDoS**

**AWS Shield Standard** מופעל אוטומטית לכל לקוחות AWS ללא תשלום. הוא מגן מפני התקפות DDoS הנפוצות ביותר ברמות 3 ו-4.

**AWS Shield Advanced** ($3,000/חודש לארגון): הגנה לכל משאבים, התרעות זמן אמת, גישה לצוות Amazon Shield Response.

**AWS WAF: המסנן**

**AWS WAF (Web Application Firewall)** פועל ברמת HTTP — הוא בוחן את תוכן בקשות האינטרנט לפני שהן מגיעות ליישום.

WAF ניתן לצרף ל-CloudFront distributions, Application Load Balancers, ו-API Gateway.

**קבוצות כללים מנוהלות**:

- **AWS Managed Rules - Core Rule Set**: מגן מפני OWASP Top 10 (SQL injection, XSS, הזרקת פקודות)
- **AWS Managed Rules - Amazon IP Reputation List**: חוסם IPים הידועים כקשורים ל-botnets

**Amazon GuardDuty: האנליסט ההתנהגות**

GuardDuty שונה מהותית מ-Shield ו-WAF. הוא לא חוסם מתקפות — הוא **מזהה התנהגות חריגה**.

GuardDuty מנתח באופן רציף:

- **יומני AWS CloudTrail**: שינויי IAM, קריאות API, כניסות למסוף
- **יומני VPC Flow**: דפוסי תנועת רשת בתוך ה-VPC
- **יומני שאילתות DNS**

"זה מה שהיה תופס את ה-IP הרומני," אמר Leo בשקט.

GuardDuty הופעל.

## סיכום

- **AWS Shield Standard**: הגנה חינמית ואוטומטית מפני DDoS ברמה 3/4.
- **AWS Shield Advanced**: הגנת DDoS פרמיום עם גישה לSRT ו-cost protection.
- **AWS WAF**: חומת אש ברמת יישום. בחינה וסינון בקשות HTTP.
- **Amazon GuardDuty**: זיהוי איומים התנהגותי. מנתח CloudTrail, VPC Flow Logs ויומני DNS.
- **CloudTrail**: הבסיס של כל רישום אבטחת AWS.

## עצות לבחינה

- **Shield Standard לעומת Advanced**: Standard חינמי ואוטומטי. Advanced עולה כסף ומוסיף SRT, cost protection.
- **אותות WAF**: "חסום SQL injection," "הגבל קריאות API," "OWASP Top 10" → WAF.
- **אותות GuardDuty**: "זהה פעילות API חריגה," "זהה IAM פגוע" → GuardDuty.

## סצנה לאחר הקרדיטים

GuardDuty הופעל.

ארבעים ושמונה שעות לאחר מכן, הוא ייצר ממצא ראשון: *"מכונת EC2 מתקשרת עם צומת יציאה Tor ידוע."*

Leo הסתכל על מזהה המכונה.

"זו מכונת הניטור הפנימית," אמר. "הזו שהקמתי להפעיל אבחונים ברשת."

"האם היא אמורה לתקשר עם צמתי יציאה Tor?"

"לא." הוא עצר. "למה?"

הוא משך את המכונה. מישהו התקין עליה כלי — סורק רשת לגיטימי בקוד פתוח שגם תקשר עם תשתית Tor לאיסוף נתונים מאונונימיים.

"אז הכלי פנה הביתה," אמרה Priya.

"בלי ידיעתי," אישר Leo.

"זה סיכון שרשרת אספקה."

Leo הסיר את הכלי. הוא קבע תהליך לסקור כל כלי צד שלישי לפני התקנה.

בפרק הבא: מה קורה כשמרכז הנתונים בווירג'יניה נעלם — ולמה Nimbus ממשיכה לפעול.

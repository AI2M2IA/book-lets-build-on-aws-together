# נספח ג: רשימת מושגים

כל מושג מפתח שהוצג בספר, ממופה לפרקו, לאנלוגיה שנעשה בה שימוש ולתחום SAA-C03 שבו הוא מופיע.

השתמש בנספח זה כאינדקס לימוד: אם אתה מעורפל לגבי מושג לפני הבחינה, מצא אותו כאן וחזור לפרקו להקשר.

---

## א

**ACU (Aurora Capacity Unit)** — יחידת המדידה לקיבולת Aurora Serverless v2. מתרחב אוטומטית. פרק 24. תחום 3.

**Alarm (CloudWatch)** — כלל שמופעל כשמדד חוצה סף, מפעיל התראה או auto scaling. פרק 7. תחום 2.

**ALB (Application Load Balancer)** — load balancer שכבה 7 שמנתב תעבורת HTTP/HTTPS לפי נתיב ו-host. פרק 7. תחום 2.

**AMI (Amazon Machine Image)** — תבנית המכילה את מערכת ההפעלה, התוכנה והתצורה למכונת EC2. פרק 4. תחום 3.

**Architecture Decision Record (ADR)** — מסמך קצר הלוכד החלטה, חלופותיה, הנימוק לה, ומה יגרום לחדייה. פרק 32. רוחב-תחום.

**Athena** — שירות שאילתות SQL serverless לנתונים ב-S3. תשלום לפי TB שנסרק. פרק 26. תחום 3.

**Auto Scaling Group (ASG)** — קבוצת מכונות EC2 המנוהלות יחד, מחליפות אוטומטית מכונות לא בריאות ומגדילות לפי עומס. פרק 7. תחומים 2, 3.

**Availability Zone (AZ)** — מרכז נתונים אחד או יותר פיזית נפרדים בתוך אזור, מחוברים בחיבורי זמן השהיה נמוך. פרק 2. תחום 2.

---

## ב

**Bucket (S3)** — קונטיינר לעצמי S3. לדליים יש שמות ייחודיים גלובלית וחיים באזור ספציפי. פרק 5. תחום 3.

---

## ג

**GuardDuty** — שירות זיהוי איומים. מנתח CloudTrail, VPC Flow Logs ולוגי DNS. מזהה אנומליות ואיומים בהתנהגות. פרק 17. תחום 1.

**Glue (AWS)** — שירות ETL serverless. Glue Crawlers מגלים סכמות; Glue Jobs מטמירים נתונים; Data Catalog מאחסן מטה-נתונים. פרק 26. תחום 3.

**GSI (Global Secondary Index)** — אינדקס חלופי על טבלת DynamoDB עם partition key ו-sort key שונים. מאפשר דפוסי שאילתה גמישים. פרק 9. תחום 3.

---

## ד

**DAX (DynamoDB Accelerator)** — מטמון בזיכרון ספציפית ל-DynamoDB. זמן השהיה קריאה במיקרושניות. פרק 9. תחום 3.

**Dead Letter Queue (DLQ)** — תור שאליו מועברות הודעות שנכשלות בעיבוד שוב ושוב. פרק 19. תחום 2.

**Dedicated Host** — שרת EC2 פיזי השמור באופן בלעדי לשימושך. נדרש לרישיונות תוכנה מסוימים. פרק 27. תחום 4.

**Defense in depth** — ריבוד שכבות אבטחה מרובות (IAM + קבוצות אבטחה + NACLs + WAF + GuardDuty) כדי שפגיעה בשכבה אחת לא תחשוף את המערכת. פרק 33. תחום 1.

**Direct Connect** — חיבור רשת פרטי ייעודי ממיקום on-premises ל-AWS. עקבי יותר מ-VPN. פרק 25. תחום 3.

**DynamoDB** — מסד נתונים NoSQL מנוהל לחלוטין עם זמן השהיה בספרות בודדות של מילישניות בכל קנה מידה. פרק 9. תחום 3.

**DynamoDB Auto Scaling** — מכוון אוטומטית קיבולת read/write provisioned על בסיס מדדי CloudWatch. פרק 29. תחום 4.

**DynamoDB Streams** — יומן שינויים מסודר בזמן של כל שינויי פריטים בטבלת DynamoDB. מועיל לעיבוד event-driven עם Lambda. פרק 9. תחום 2.

---

## ה

**Envelope encryption** — דפוס שבו נתונים מוצפנים עם data key (DEK), ו-DEK מוצפן עם master key (CMK ב-KMS). פרק 16. תחום 1.

**EventBridge** — אוטובוס אירועים לניתוב אירועים משירותי AWS, שותפי SaaS ומקורות מותאמים אישית ליעדים. פרק 22. תחום 2.

---

## ו

**VPC (Virtual Private Cloud)** — רשת וירטואלית מבודדת ב-AWS המכילה תת-רשתות, טבלאות מסלול ושערים. פרק 11. תחום 1.

**VPC Flow Logs** — לוכד מידע על תעבורת IP אל/מ-ממשקי רשת ב-VPC. פרק 17. תחום 1.

**VPC Peering** — חיבור רשת בין שני VPCs המאפשר תעבורה ביניהם באמצעות כתובות IP פרטיות. פרק 11. תחום 3.

**VPC Endpoint** — מחבר משאבי VPC לשירותי AWS דרך הרשת הפרטית של AWS. Gateway (חינם, S3/DynamoDB) ו-Interface (בתשלום, רוב השירותים האחרים). פרק 30. תחומים 1, 4.

## י

**Idempotency** — המאפיין של פעולה המייצרת את אותה תוצאה בין אם נקראת פעם אחת ובין אם פעמים רבות. קריטי למערכות מבוזרות (החזרים, תשלומים, עיבוד הזמנות). פרק 32. רוחב-תחום.

**"It depends"** — התשובה הכנה לרוב שאלות הארכיטקטורה, שחייבת תמיד להיות מושלמת: "תלוי בדפוס הגישה / קנה המידה / תוצאת הכשל / אילוץ העלות." פרק 33. רוחב-תחום.

## כ

**Kinesis Data Firehose** — מסירה מנוהלת של נתוני זרימה ל-S3, Redshift, OpenSearch. ללא ניהול צרכן. פרק 26. תחום 3.

**Kinesis Data Streams** — זרם אירועים מסודר בזמן אמיתי. עמיד, ניתן ל-replay. נמדד ב-shards. פרק 26. תחום 3.

**KMS (Key Management Service)** — יוצר, מאחסן ושולט במפתחות קריפטוגרפיים להצפנה בשאר. פרק 16. תחום 1.

---

## ל

**Lambda** — פונקציות serverless שמופעלות על ידי אירועים. תשלום לפי הפעלה ולפי ms. מקסימום 15 דקות. פרק 20. תחומים 2, 3, 4.

**Latency-based routing (Route 53)** — מנתב שאילתות DNS לאזור AWS עם זמן ההשהיה הנמוך ביותר הנמדד. פרק 12. תחום 3.

**Launch template** — תבנית עם גרסאות המציינת תצורת מכונת EC2 ל-Auto Scaling Groups. פרק 7. תחום 3.

**Least privilege** — שיטת עבודה מומלצת של IAM: הענק רק את ההרשאות הנחוצות, לא יותר. פרק 3. תחום 1.

**Lifecycle policy (S3)** — כללים שמעבירים אוטומטית עצמים למחלקות אחסון זולות יותר או מוחקים אותם לפי גיל. פרק 23. תחום 4.

---

## מ

**Multi-AZ (RDS)** — replica standby סינכרוני ב-AZ שונה עם כשל-אוטומטי. RPO ~0, RTO ~60 שניות. לזמינות גבוהה, לא להגדלת קריאות. פרקים 8, 18. תחום 2.

**Multi-Region** — פריסת רכיבי אפליקציה על פני אזורי AWS מרובים לצורך יתירות גיאוגרפית וביצועים גלובליים. פרק 18. תחום 2.

---

## נ

**NACL (Network Access Control List)** — חומת אש stateless ברמת תת-הרשת. דורש כללי כניסה ויציאה כאחד. כללים מוערכים בסדר מספרי. פרק 15. תחום 1.

**NAT Gateway** — מאפשר למכונות בתת-רשתות פרטיות לבצע חיבורים יוצאים לאינטרנט. גובה $0.045/GB מעובד. פרקים 11, 30. תחום 4.

---

## ע

**EC2 (Elastic Compute Cloud)** — מכונות וירטואליות בענן. פרק 4. תחום 3.

**ECS (Elastic Container Service)** — תזמור containers מנוהל. Fargate launch type מסיר ניהול EC2 לחלוטין. פרק 21. תחומים 2, 3.

**EFS (Elastic File System)** — מערכת קבצים NFS משותפת נגישה ממכונות EC2 מרובות. מתרחב אוטומטית. פרק 6. תחום 3.

**EKS (Elastic Kubernetes Service)** — control plane Kubernetes מנוהל על AWS. פרק 21. תחום 3.

**ElastiCache** — שירות מטמון בזיכרון מנוהל. Redis (עשיר יותר בתכונות) או Memcached (פשוט יותר). פרק 10. תחום 3.

**EBS (Elastic Block Store)** — אחסון בלוקים מתמשך למכונת EC2 בודדת. Snapshots לגיבוי. פרק 6. תחום 3.

---

## פ

**Failover routing (Route 53)** — מנתב תעבורה לנקודת קצה משנית כשהראשית נכשלת ב-health checks. פרק 12. תחום 2.

**Fargate** — מנוע חישוב serverless ל-ECS ו-EKS. ללא מכונות EC2 לניהול. פרק 21. תחום 3.

**Fan-out pattern** — SNS topic אחד מוסר את אותה הודעה לתורי SQS מרובים בו-זמנית. פרק 19. תחום 2.

**FIFO queue (SQS)** — exactly-once processing, strict ordering. תפוקה נמוכה מתורות standard. פרק 19. תחום 2.

## ר

**RDS (Relational Database Service)** — מסד נתונים רלציוני מנוהל. מטפל בגיבויים, תיקון, כשל-אוטומטי. פרק 8. תחום 3.

**RDS Proxy** — מנהל מאגר חיבורים בין Lambda/אפליקציה ו-RDS, מונע מיצוי חיבורים. פרק 8. תחום 3.

**Read Replica (RDS)** — עותק אסינכרוני של מסד הנתונים להגדלת קריאות. לא מספק כשל-אוטומטי. פרקים 8, 24. תחום 3.

**Redis** — מאגר מבני נתונים בזיכרון לmטמון, ניהול סשנים, לוחות תוצאות בזמן אמיתי, pub/sub. פרק 10. תחום 3.

**Reserved Instance (EC2)** — התחייבות לשימוש בסוג מכונה ספציפי באזור ספציפי ל-1 או 3 שנים בתמורה להנחה. פרק 27. תחום 4.

**Route 53** — שירות DNS ורשם תחומים של AWS. תומך במדיניות ניתוב מרובות. פרק 12. תחומים 2, 3.

**RPO (Recovery Point Objective)** — אובדן נתונים מקסימלי מקובל הנמדד בזמן. "כמה נתונים אנחנו יכולים להרשות לאבד?" פרק 18. תחום 2.

**RTO (Recovery Time Objective)** — זמן שחזור שירות מקסימלי מקובל לאחר כשל. "כמה זמן אנחנו יכולים להיות מושבתים?" פרק 18. תחום 2.

**Runbook** — הוראות שלב-אחר-שלב לתפעול מערכת, ספציפית לתגובה לאירועים. פרק 32. רוחב-תחום.

## ש

**Shared Responsibility Model** — AWS אחראי על אבטחה *של* הענן (תשתית); אתה אחראי על אבטחה *בתוך* הענן (נתונים, תצורה, גישה). פרק 1. תחום 1.

**Shield** — הגנת DDoS. Standard: חינם, אוטומטי. Advanced: בתשלום, עם תמיכת DRT והגנה פיננסית. פרק 17. תחום 1.

**SNS (Simple Notification Service)** — הודעות pub/sub. דוחף הודעות לכל המנויים בו-זמנית. דפוס fan-out. פרק 19. תחום 2.

**SQS (Simple Queue Service)** — תור הודעות מנוהל. מנתק מפיקים מצרכנים. תורות Standard (at-least-once) ו-FIFO (exactly-once). פרק 19. תחום 2.

**Step Functions** — שירות תזמור תהליכי עבודה serverless. State machines לתיאום שירותי AWS. פרק 22. תחום 2.

**S3 Intelligent-Tiering** — מעביר אוטומטית עצמי S3 בין שכבות גישה על בסיס דפוסי גישה. ללא דמי שחזור. פרק 23. תחום 4.

**S3 Select** — שולף תת-קבוצה של תוכן עצם S3 באמצעות ביטויי SQL, מפחית העברת נתונים. פרק 30. תחום 4.

**Savings Plan** — מודל תמחור גמיש המתחייב לסכום של הוצאה שעתית בתמורה להנחה. גמיש יותר מ-Reserved Instances. פרק 27. תחום 4.

**SCP (Service Control Policy)** — מדיניות AWS Organizations שמגבילה את ההרשאות המקסימליות הזמינות לחשבונות ב-OU. פרק 14. תחום 1.

**Secrets Manager** — מאחסן ומסובב אוטומטית secrets (סיסמאות מסד נתונים, API keys). פרק 16. תחום 1.

**Security group** — חומת אש וירטואלית stateful ברמת המכונה. כללי allow בלבד; תעבורת חזרה היא אוטומטית. פרק 15. תחום 1.

---

## ת

**Transit Gateway** — רכזת לקישוריות VPC ו-on-premises. מאפשר ניתוב עקיף (בשונה מ-VPC peering). פרק 25. תחום 3.

**TTL (Time to Live)** — חותמת זמן שלאחריה DynamoDB מוחק אוטומטית פריט. מועיל גם ב-DNS (כמה זמן resolvers שומרים רשומה במטמון) ובmטמון (כמה זמן ערך במטמון תקף). פרקים 9, 12. תחום 3.
